# Kurisu — инструкция под телефон (финальная)

## Что это
Веб-приложение (React + Vite) с модульным «мозгом» Курису.
Это не магазинный APK из коробки, но на телефоне им можно пользоваться.

---

## Быстрый запуск на Android

### Способ 1 — с компьютера (проще)
1. Распакуй архив на ПК
2. Установи Node.js LTS: https://nodejs.org
3. В папке `kurisu_webapp`:
   ```bash
   cp .env.example .env
   ```
4. Открой `.env` и впиши:
   ```
   GEMINI_API_KEY=твой_ключ_из_Google_AI_Studio
   ```
5. Установи и запусти:
   ```bash
   npm install
   npm run dev
   ```
6. В терминале будет адрес вида `http://192.168.x.x:3000`
7. На телефоне открой этот адрес в Chrome (телефон и ПК в одной Wi‑Fi сети)
8. В Chrome: Меню → «Добавить на главный экран» (PWA)

### Способ 2 — Termux на телефоне
1. Установи Termux из F-Droid (не устаревший с Play, если глючит)
2. ```bash
   pkg update && pkg install nodejs git
   ```
3. Скопируй проект в Termux (через `~/storage` или git)
4. ```bash
   cd kurisu_webapp
   cp .env.example .env
   # впиши GEMINI_API_KEY
   npm install
   npm run dev -- --host 0.0.0.0
   ```
5. Открой в Chrome `http://127.0.0.1:3000`

### Способ 3 — позже APK-оболочка
Обернуть этот же веб в Capacitor → получить APK.
Это отдельный шаг, ядро личности уже готово переносить.

## Обязательно для «живости»
- Без `GEMINI_API_KEY` ответы в облаке не раскроются (offline = ограниченный режим)
- Разреши уведомления браузеру, если хочешь пуши
- Не жди чудес от offline-движка — это не полноценный LLM

## Может ли она писать сама, пока ты сидишь в чате молча?
**Да, заложено.**

Модуль `PresenceAndIdle`:
- если ты в чате, но молчишь ~1–1.5+ минуты → режим `in_chat_idle`
- появляются **мысли / желания** (пузыри, не всегда речь)
- при выполнении лимитов может инициировать **реплику в чат**
- лимиты защищают от спама

Важно: UI должен вызывать `tick()` по таймеру и при необходимости `pickIdleSpeech()` + реально пост сообщения. Иначе намерение останется только внутренним.

## Индикации на экране (что показывать)
Из `StatusIndicators` + bubbles:
- Настроение, любопытство, доверие, стадия отношений
- Текущая мысль / желание
- Выражение, среда, энергия
- «ты в чате, молчишь» / «говорит» / «оффлайн»
- Активная цель

Рекомендуемый UI:
```
[Аватар]
мысль: «...»
желание: «...»
чипы: Спокойна | Доверие 42 | Лаб | Idle
[Чат]
```

## Если что-то не запускается
1. Проверь Node версию (`node -v` ≥ 18)
2. Удали `node_modules` и снова `npm install`
3. Проверь, что порт не занят
4. API key без кавычек и пробелов в `.env`
5. На телефоне используй HTTP-адрес ПК в локальной сети, не `localhost` с ПК-адреса
