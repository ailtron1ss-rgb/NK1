# NeuroCore Pass Protocol

Каждый проход обязан одновременно двигать нейронность или уменьшать архитектурный долг.
Новый номер версии без измеримого изменения не считается прогрессом.

## DISCOVER

1. Проверить актуальные исследования и живые reference-реализации.
2. Найти уже существующие механизмы в current и legacy.
3. Определить owner, state contract и возможные дубликаты.
4. Сформулировать одну причинно проверяемую гипотезу.

## ISOLATE

1. Кандидат сначала живёт вне current runtime.
2. Для кандидата фиксируются parameter/compute/state budgets.
3. Baseline выбирается до запуска эксперимента.
4. Ablation должен быть возможен без переписывания baseline.

## BUILD

1. Реализовать кандидат в отдельной research surface или как заменяемый компонент current owner.
2. Не создавать новый VXX subclass для каждого эксперимента.
3. Не добавлять новый memory owner ради нового механизма.
4. Писать invariant-тесты одновременно с кодом.

## QUALIFY

Для существенного quantitative claim:

- минимум 5 seeds;
- matched baseline;
- качество + latency/compute + память, если применимо;
- ablation ключевого механизма;
- long-horizon test для recurrence/memory;
- проверка градиентного покрытия и state integrity, если механизм обучаемый.

## PROMOTE / REJECT

**PROMOTE**: механизм получает место в current owner только после воспроизводимого выигрыша или доказанного
исправления корректности при нейтральной/лучшей стоимости.

**REJECT**: кандидат не попадает в current. Его код/результаты сохраняются как evidence или research snapshot,
чтобы не повторять тот же эксперимент и не загрязнять runtime.

## BOUNDARIES

- `forward()` определяет границу независимой обучающей последовательности.
- `step()` определяет непрерывный runtime stream.
- Sequence-local statistics не должны переноситься между несвязанными training episodes.
- Runtime state должен быть сериализуемым и восстанавливаемым.

## Источник истины

1. Исполняемый current code.
2. Тесты.
3. Benchmark/evidence.
4. Checkpoint state/migrations.
5. Документация.

Документация никогда не повышает статус механизма автоматически.
