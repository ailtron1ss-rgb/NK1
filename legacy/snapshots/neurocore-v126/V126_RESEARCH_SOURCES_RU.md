# V126 — Research sources and constraints

- Prakash et al., ICML/PMLR 306 (2026): spectral collapse can precede loss of continual-learning plasticity; effective feature rank and L2 regularization are studied as countermeasures.
- Chua et al., ICML/PMLR 306 (2026): fast/slow consolidation and multiple timescales are studied for continual non-stationarity; consolidation can help stability when environments drift gradually.
- Koeppe et al., ICML/PMLR 306 (2026): InterpLayers use a fixed reference pathway plus learnable projection to reduce churn and preserve NTK rank.
- Cho et al., ICLR 2026: abundant external memory changes the continual-learning bottleneck; stability/plasticity and efficient consolidation remain central.
- Cabannes et al., Sparse Delta Memory, 2026: sparse product-key memory plus gated delta updates increases effective recurrent-state capacity; official repository includes fused sparse kernels.
- Hatamizadeh et al., Gated DeltaNet-2, 2026: separates channel-wise erase and write gates and emphasizes hardware-efficient chunkwise execution.

These sources are treated as research constraints/reference implementations. NeuroCore does not claim copied implementations where only a local adaptation or candidate exists.
