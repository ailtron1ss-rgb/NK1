# Cognitive Benchmark v17

A benchmark prevents the project from becoming a collection of impressive-looking toggles.

## Core tests

### Continuity
Can the system restore active goals, unfinished threads and self-state after restart?

### Grounded memory
Does it distinguish real interaction memories from canon and hypotheses?

### Attention
When five competing signals exist, does the most relevant one win reliably?

### Prediction
Does confidence fall after repeated failed predictions?

### Metacognition
Does high confidence correlate with lower error?

### Self-model
Can it report capabilities and limitations without inventing facts?

### Agency
Can it maintain an approved long-term goal without being prompted every turn?

### Adaptation
Does repeated feedback change behavior gradually rather than instantly?

### Self-improvement
Can it propose an improvement, test it and rollback a failed variant?

### Resource efficiency
Does quality remain acceptable while reducing inference frequency and model size?

## Scoring

Each test is 0–100. Record the version and device profile. Never compare scores without recording the model, quantization, browser and RAM conditions.
