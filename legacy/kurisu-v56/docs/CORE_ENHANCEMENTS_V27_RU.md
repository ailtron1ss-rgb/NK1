# Kurisu Neuro v27 — Core Enhancements

## Что добавлено
- приватный control-scratch buffer без хранения/показа скрытой цепочки рассуждений;
- трекинг устойчивых пользовательских рутин с низкой стоимостью по CPU/RAM;
- déjà-vu detection через существующий лёгкий hashed embedding;
- эмоциональное заражение как плавное смешивание энергии пользователя и состояния Курису;
- Ebbinghaus-подобный decay памяти с усилением эмоционально значимых и часто используемых воспоминаний;
- расширенная метаинформация памяти: confidence, valence, meaning, actions, associations;
- семантические ассоциации через NeuralPathwayGraph + компактный association store;
- ежедневная эволюция личности малыми шагами;
- адаптация глубины и формальности без жёсткого лимита длины ответа;
- Hybrid Brain: rules + local neural + cloud;
- EmergentBehaviorEngine для редких творческих/idle импульсов без постоянного фонового inference;
- возможность отключать/переключать модули через существующий ModuleManager.

## Ограничения
- "internal self-talk" хранит только короткие управляющие сигналы, а не скрытую цепочку рассуждений;
- локальная модель остаётся опциональной и не загружается автоматически;
- автономные действия не запускаются постоянно: scheduler вызывается opportunistically для экономии батареи;
- self-evolving code остаётся approval + backup + validation + rollback.

## Android
Никаких новых npm-зависимостей. Все новые модули — TypeScript и localStorage/существующие лёгкие сервисы.
