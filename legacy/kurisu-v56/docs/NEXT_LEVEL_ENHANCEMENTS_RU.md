# Next Level Enhancements — v27

## 1. Micro-enhancements
- Internal control scratch: only compact control variables, never raw chain-of-thought.
- Routine tracker: detects stable interaction patterns, not one-off guesses.
- Déjà-vu: compares current input with retrieved memories using the existing 64-d hashed embedding.
- Emotional contagion: 28% gentle pull toward user energy, preventing abrupt mood jumps.
- Human texture: prompted as rare self-correction/pauses, never random typos.

## 2. Memory
Retention is now a hybrid score:
- semantic similarity;
- Ebbinghaus-style forgetting;
- recency;
- emotional intensity;
- retention priority;
- access frequency;
- confidence.

Each structured experience may also carry meaning, actions, valence and associations.

## 3. Personality
Traits evolve slowly during daily review. The user's vocabulary is observed as style signal, but Kurisu does not blindly mirror slang or identity.

## 4. Emergence
Creative/dream impulses are opportunistic and budgeted. No permanent background LLM loop is used on Android.

## 5. Hybrid architecture
Rules decide safety/routing and deterministic state transitions; neural generation handles local language; cloud handles difficult/high-quality generation.

## 6. Self-evolution
The SelfEvolutionLab can generate source scaffolds for new modules. Scaffolds are drafts only. A module must pass review/tests and explicit approval before integration. Existing rollback remains.
