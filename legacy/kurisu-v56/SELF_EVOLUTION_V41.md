# Neuro-Kurisu v4.1 — safe self-evolution layer

## Что реально умеет система
- Анализирует собственные runtime-метрики, память, шаблонность и поведение.
- Формирует предложения по улучшению конфигурации.
- Перед применением создаёт snapshot и поддерживает rollback.
- Может работать с allowlist исходников на сервере для аудита и typecheck.
- Не выполняет произвольный сгенерированный код автоматически.

## Почему это важно
В браузерном Node/Termux приложении нельзя безопасно и надёжно дать модели безусловное право переписывать весь проект. Поэтому эволюция разделена на безопасные уровни:
1. runtime-конфигурация — автоматический анализ, применение только после подтверждения;
2. исходники — аудит, предложение патча, резервная копия, проверка `tsc --noEmit`, затем явное подтверждение;
3. тяжёлое обучение весов — только внешним подготовленным pipeline, не в фоне телефона.

## Mobile policy
Performance / Balanced / PowerSave управляют частотой аватара, фоновыми задачами и загрузкой локальной модели. CPU temperature доступна только через native bridge; браузер не подделывает этот показатель.
