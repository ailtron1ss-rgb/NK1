# Исправления сборки Neuro Kurisu v4.1

## Исправлена причина TS7026 / TS7006 в SettingsPanel.tsx

Причина была не в JSX-коде строк 435–529. В `tsconfig.json` были явно разрешены только типы Node:

```json
"types": ["node"]
```

Из-за этого TypeScript не подключал декларации React/ReactDOM и не видел `JSX.IntrinsicElements`. Поэтому `<input>`, `<button>`, `<div>`, `<span>` и параметры событий/`.map()` начали превращаться в каскад TS7026/TS7006.

### Что изменено

1. Добавлены dev-зависимости:
   - `@types/react`
   - `@types/react-dom`
2. `tsconfig.json` теперь явно подключает:
   - `node`
   - `react`
   - `react-dom`
3. Логика `SettingsPanel.tsx` не переписывалась без необходимости: после восстановления React typings TypeScript корректно выводит типы `e`, `m` и JSX-элементов.
4. В проект добавлен этот отчёт, чтобы причина ошибки была зафиксирована.

## Важно

В текущем окружении архива нет `node_modules`, а доступ к npm registry из среды проверки недоступен, поэтому фактический `npm run lint`/`npm run build` здесь нельзя честно выполнить. После распаковки на телефоне необходимо выполнить `npm install`, затем проверки из инструкции ниже.
