# NK1 WorkPass355 — целостность единого когнитивного субстрата

**Дата:** 2026-10-26  
**Ветка:** work/nk1-substrate-restore-integrity-2026-10-26-r1  
**База:** workpass354-completion-anchor-provenance  
**Область:** границы доверия для производного состояния, объединяющего модель себя, мира, предсказания, ресурсы и происхождение наблюдений.

## Найденная проблема

Модуль UnifiedCognitiveSubstrate вычислял межсистемные метрики, но старый restore() делал spread произвольного сохранённого объекта и его вложенных секций. Такой путь не проверял schema version, мог принять некорректные счётчики/числовые значения и лишние свойства. integrate() обрезал часть значений, но не отклонял неверный тик, дубликат тика, невалидные счётчики и отсутствующие секции до изменения состояния. Существующий CI также не запускал тест субстрата по собственным изменениям.

## Изменения в коде

1. Восстановление строится из allow-list известных полей; prototype-свойства и произвольные поля не переносятся в состояние.
2. Чтение полей через descriptor-based helper не исполняет getter-функции пользовательского JS-объекта.
3. Неизвестная/будущая schema version отклоняется до замены текущего рабочего состояния.
4. Повреждённые сохранённые метрики и счётчики нормализуются консервативными fallback-значениями; текст очищается от управляющих символов и ограничивается по длине.
5. Live integrate() проверяет безопасный integer tick, монотонность тиков, обязательные секции, все метрики в диапазоне [0,1], все счётчики как неотрицательные safe integers и необязательное поле reason до вычисления/фиксации следующего состояния.
6. Состояние фиксируется только после полной валидации — ошибка не оставляет частичный цикл и не изменяет прежний snapshot.
7. WorkPass331 workflow теперь отслеживает изменения модуля/теста и выполняет профильный тест npm run test:substrate.

## Регрессии

Добавлены тесты на future schema version, accessor getter без побочного эффекта, prototype pollution через наследуемые поля, sanitization счётчиков/метрик/строк, отсутствие передачи неизвестных полей, повторный тик, метрику вне диапазона, unsafe counter и сохранение состояния после отказа.

## Проверка и ограничения

- **Ожидаемое CI:** WorkPass331 unified cognitive kernel — запускается после публикации PR; итог нужно подтвердить на точном новом SHA.
- **Локальный запуск:** в данной сессии исходный репозиторий не клонировался, поэтому локальный Node/npm тест здесь не заявляется.
- Этот этап укрепляет одну интеграционную границу и не означает, что весь NK1 уже собран в единый runtime: текущая исходная ветка всё ещё не содержит проводку субстрата в OrganismRuntime; портировать/согласовать runtime wiring из PR #136 нужно отдельным проверяемым этапом.
- Измеренный прирост обучения, реальное Android/Live2D/voice E2E и полная готовность release не утверждаются.
- main и опубликованный Release ZIP не менялись.
