# P51 — Grounded Causal Workspace

Большой шаг переводит Kurisu от отдельного causal engine к лёгкому общему пространству, где наблюдения, семантические якоря, действия, гипотезы, интервенции и контрфакты сохраняются в одной проверяемой структуре.

Главный принцип: **grounding ≠ truth ≠ consciousness**. Система хранит confidence и provenance-подобные источники, но не объявляет наличие phenomenal consciousness.

## Состав
- symbolic semantic anchors с bounded retention;
- causal hypothesis tracking;
- intervention evidence;
- counterfactual branches;
- workspace broadcast summary;
- отдельные metrics semanticCoverage / groundingQuality / causalReadiness / selfWorldAlignment;
- schema 51 migration и restart continuity.

## Большой замысел
P51 подготовлен как фундамент для следующего шага: настоящий Self–World model с multi-hypothesis reasoning, causal experiments и semantic backends. Тяжёлые embeddings/VLM не запускаются на каждом phone tick.
