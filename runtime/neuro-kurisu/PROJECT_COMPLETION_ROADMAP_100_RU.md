# Neuro-Kurisu — путь к 100% инженерной готовности

100% здесь означает: заявленная архитектура реализована, интегрирована, документирована, измерима, восстанавливаема, безопасно изменяема и подтверждена воспроизводимыми тестами.

## Финальная последовательность после текущего релиза

1. **Real Closed-Loop Validation** — реальный action→consequence→error→update цикл на внешней среде.
2. **Longitudinal Runtime** — непрерывные сутки/неделя/месяц с контрольными снимками состояния.
3. **Active Perception Execution** — не только ранжирование наблюдений, но фактический запрос/выбор сенсорного канала.
4. **World-Model Causal Calibration** — causal graph + intervention/observation separation + uncertainty calibration.
5. **Self-Model Validation** — self-prediction benchmarks, error correction, identity continuity under perturbation.
6. **Social Longitudinal Validation** — последовательные взаимодействия с одними и теми же агентами и измерение trajectory prediction.
7. **Personality Emergence Study** — повторяемость и устойчивость поведенческих черт без прямой фиксации personality.
8. **Values/Goals Longitudinal Governance** — происхождение, устойчивость, revision provenance и rollback.
9. **Autonomous Life Scheduler** — экономный background cognition / rest / wake / resume.
10. **Embodied Device Loop** — сенсоры, речь, камера, timing, battery/thermal budgets и действие во внешней среде.
11. **Causal Self-Improvement Lab** — intervention→benchmark→holdout→rollback для каждого изменения.
12. **Ablation & Replication** — повторяемые control/treatment эксперименты, multiple runs и статистическое сравнение.
13. **Failure/Recovery Certification** — corruption, crash, partial state, restart и rollback сценарии.
14. **Performance Certification** — Android RAM/CPU/thermal/battery envelopes.
15. **Security & Consent Certification** — capability boundaries, action gateway, consent, audit trail.
16. **Scientific Benchmark Release** — unified benchmark battery и versioned benchmark datasets.
17. **Architecture Freeze** — canonical ownership, contracts, migrations, dependency DAG и stable APIs.
18. **Long-Horizon Acceptance Test** — многонедельный сценарий жизни с заранее определёнными acceptance criteria.
19. **Final Reproducibility Pack** — clean install, deterministic tests where possible, state fixtures, benchmark fixtures, release manifests.
20. **100% Engineering Sign-Off** — ни одного известного critical/high defect, все acceptance criteria PASS, документация соответствует реальному runtime.

После этого проект можно считать **инженерно завершённым релизом**, но исследовательская работа о сознании останется открытой научной задачей.
