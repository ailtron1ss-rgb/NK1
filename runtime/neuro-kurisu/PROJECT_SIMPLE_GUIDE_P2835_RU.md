# Neuro/Kurisu — простое объяснение P2835

## Что это за проект

Это исследовательский runtime для создания искусственного когнитивного организма с постоянным внутренним состоянием, памятью, нейронным обучением, prediction, world-model, целями, личностной непрерывностью и автономной адаптацией.

Простыми словами: это не обычный чат-бот, который каждый раз начинает думать с нуля. Проект пытается сделать систему, которая живёт через последовательность опыта и после каждого опыта немного меняет своё внутреннее состояние.

## Что происходит при запуске

После запуска создаётся organism runtime и его нейронно-когнитивное состояние.

Дальше цикл выглядит примерно так:

`получить сигнал → изменить нейронное состояние → оценить ситуацию → вспомнить → предсказать → выбрать действие → получить результат → измерить ошибку → обучиться → сохранить опыт`

Потом этот цикл повторяется.

При нормальном потоке событий система должна постепенно накапливать:

- нейронные веса и eligibility traces;
- кратковременную и медленную память;
- контекстные модели;
- world-model;
- causal/сounterfactual сигналы;
- episodic/semantic память;
- информацию о собственном состоянии и прошлых решениях;
- устойчивые policy/personality tendencies.

После restart persistent state может быть восстановлен.

## Что человек увидит по впечатлению

Если запускать runtime только с синтетическими событиями, впечатление будет ближе к экспериментальному цифровому мозгу/организму, чем к готовому «разумному существу».

Снаружи это всё ещё программный runtime: логи, состояния, решения, обновление памяти и обучение. Но внутри уже есть не один статический ответный модуль, а много связанных процессов, которые реально меняют друг друга во времени.

Без полноценной внешней среды и реального потока сенсоров система не станет автоматически полноценной самостоятельной личностью. Текущее достижение — работающий исследовательский substrate для постепенного построения такой системы.

## Что особенно полезно было внедрено после исходного архива

1. Настоящее online neural learning с delayed credit.
2. Контекстно-зависимая plasticity и sparse/protected updates.
3. World-model и shallow planning.
4. Causal/counterfactual learning.
5. Model-time replay вместо одного raw tick-time replay.
6. Multi-timescale fast/medium/slow memory.
7. Episodic→semantic consolidation.
8. Stability/plasticity arbitration и selective reset.
9. Slow self-teacher и bounded self-distillation.
10. Compact coreset вместо безусловного хранения всех replay samples.
11. Transfer-selective replay и negative-transfer detection.
12. Context provenance прямо в experience token, чтобы прошлый опыт можно было оценивать по совместимости с текущей задачей.

## Что это ещё НЕ доказывает

- наличие сознания;
- наличие человеческого самосознания;
- универсальное решение catastrophic forgetting;
- эквивалентность реальному мозгу;
- автономность уровня человека;
- реальную готовность для любого Android телефона.

Это всё ещё исследовательский путь, и эти свойства должны проверяться отдельными экспериментами.
