# Release 14.0.0 — P48 Functional Awareness

## Большой шаг

P48 превращает несколько существующих cognitive подсистем в более явный функциональный контур: workspace ignition, higher-order self-monitoring и interoceptive homeostasis.

## Ключевые изменения

- Добавлен `P48FunctionalAwarenessCore`.
- Добавлена явная модель interoceptive error/free-energy proxy.
- Добавлен higher-order self-representation и monitoring lag.
- Добавлен отдельный набор из 10 functional indicator domains.
- Functional/causal/longitudinal evidence разделены; causal-integration остаётся нулём без независимого эксперимента.
- P48 сохраняется внутри `advanced` state и совместим со schema 48.
- Обновлены release manifests до 14.0.0 / Core 43 / P48.

## Научная граница

P48 является инженерным functional-awareness layer. Он не является доказательством субъективного опыта или phenomenal consciousness.
