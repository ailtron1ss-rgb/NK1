# B265 — прогресс большого апдейта

Дата: 12 сентября 2026

## Цель

B265 закрывает главный пробел B264: политика больше не должна быть единственным источником оценки собственного успеха. Вводится независимый evaluator, который сам разворачивает многошаговую траекторию в контролируемой среде, независимо вычисляет reward, сравнивает policy с baseline и random policy, а затем проверяет holdout, counterfactual effect, calibration и persistence.

## Сделано

1. Добавлен `B265IndependentPolicyEvaluator`.
2. Evaluator не читает self-reported reward policy: reward приходит только из `B265Environment.transition()`.
3. Поддержан многошаговый horizon (по умолчанию 8).
4. Добавлен baseline и random policy.
5. Добавлен holdout по отдельным task environments.
6. Добавлен counterfactual first-action comparison.
7. Добавлена evaluator calibration.
8. Добавлен Core integration API.
9. Добавлена persistence/migration схема.
10. Добавлены standalone, Core и migration tests.
11. Перепроверена B264 regression.
12. Проведены release-gates по отдельности.

## Архитектурный смысл

Цепочка теперь:

`P27 latent -> B259 recurrent -> B260 causal memory -> B261 world model -> B262 multi-timescale dynamics -> B263 action causality -> B264 causal policy -> external evaluator -> multi-step consequence -> independent score -> policy evidence`

Главное отличие B265 от прошлых проходов: evaluator принципиально вынесен за пределы policy learning state.

## Ограничения

- Среда evaluator всё ещё контролируемая цифровая среда.
- B265 не доказывает внешнюю физическую causal efficacy.
- Полный executable syntax sweep всего дерева снова превысил доступное время среды и помечен `BLOCKED_BY_ENV_TIMEOUT`.
- Full historical audit не объявлен PASS.

## Следующий шаг

B266 должен перенести независимое оценивание от коротких синтетических задач к долгим composite tasks, где evaluator создаёт сменяющиеся задачи, скрытые режимы среды, delayed credit и независимые intervention baselines.
