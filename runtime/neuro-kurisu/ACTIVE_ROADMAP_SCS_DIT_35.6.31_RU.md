# Active Roadmap — Stage-30 / B381+

## Priority 1 — real embodied life
1. Device gate execution on actual Android/Termux.
2. Independent sensor verification around autonomous actions.
3. Physical closed-loop learning on real device only.
4. 1000/5000/10000+ cycle endurance.

## Priority 2 — developmental personality
5. Extend verified experience consolidation from action values to stable preference/value traces.
6. Contradiction handling when repeated verified outcomes conflict with older preferences.
7. Context-conditioned developmental memory so personality changes are not globalized from one context.
8. Separate episodic memory retrieval from semantic/generalized value learning.
9. Demonstrate that clearing historical memory changes future behavior, while unrelated holdout behavior remains stable.

## Priority 3 — self/world development
10. Bind developmental experience to autobiographical self-model.
11. Improve world-model transition calibration under changing environments.
12. Improve planning from short predictive selection toward reusable multi-step policies.
13. Add stronger metacognitive uncertainty calibration without creating a new decision owner.

## Priority 4 — survival and continuity
14. Long-horizon persistence with crash/restart.
15. Thermal/battery/resource-aware throttling.
16. Sensor dropout and partial observability recovery.
17. Safe degraded operation on medium Android.

## Rule
Prefer integration and causal strengthening over creation of parallel B-modules. Every new mechanism requires WHY/HOW/CAUSAL PATH/TEST/ABLATION/PERFORMANCE evidence.
