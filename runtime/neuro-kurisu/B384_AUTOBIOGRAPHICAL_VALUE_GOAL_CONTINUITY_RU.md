# B384 — Автобиографическая непрерывность ценностей и целей

## Цель
B384 связывает уже доказанные B380 temporal experience, B382/B383 contextual memory и canonical B365 neural policy в единый developmental contour. Новая подсистема не является отдельным decision owner.

## Причинная цепь
`verified experience -> autobiographical episode -> value revision -> goal coupling -> B365 policy -> next decision`

## Реализовано
- bounded autobiographical developmental episodes (96);
- 8 evidence-weighted values: truth, evidence, autonomy, responsibility, curiosity, preservation, connection, novelty;
- goal-value coupling до 24 целей;
- retrieval по context/action/goal;
- contradiction/conflict counters;
- identity continuity/coherence/value stability;
- history activation gate: пустая история не влияет на policy;
- только verified independent evidence разрешает developmental revision;
- persistence/restart через B365 state;
- B380 close() автоматически промотирует verified temporal token в B384 через существующий B365 consolidateExperience();
- causal OFF/reset/knockout coverage.

## Почему это один coherent organism
B365 остаётся единственным canonical decision owner. B384 только изменяет уже существующее developmental state и добавляет evidence-weighted bias в B365 policy после накопления достаточной проверенной истории.
