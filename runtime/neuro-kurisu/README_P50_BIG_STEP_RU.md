# P50 — Causal Self-World

Большой архитектурный шаг: единый causal substrate для связки self → action → outcome → world, counterfactual records, intervention errors и longitudinal alignment. P50 измеряет функциональную причинную согласованность, но не объявляет сознание доказанным.

## Ключевые идеи
- causal graph вместо изолированных score;
- counterfactual ledger;
- attribution error;
- self/world alignment;
- bounded graph;
- state schema 50.
