## Что сделано

B263 переносит brain branch от прогнозирования последствий к отдельному причинному слою действия. Система теперь хранит фактические переходы `before -> action -> after -> reward`, обучает action-conditioned delta model, ведёт shuffled-action baseline, считает causal gain, проводит `do(action)` intervention, action comparison, replay, holdout и action ablation.

B263 подключён внутрь живого `OrganismCore`: реальные P27-latent до/после действия используются для обучения, а состояние сохраняется и восстанавливается вместе с B259/B260/B261/B262.

## Что это ДОКАЗЫВАЕТ

1. Action identity содержит измеряемую предсказательную информацию о downstream latent change.
2. Этот сигнал сохраняется на holdout и не возникает только из train fit.
3. Replay способен дополнительно изменять causal model.
4. Система может вычислять `do(action)`-подобные interventions над собственной learned dynamics.
5. Состояние причинной модели является частью жизненного цикла OrganismCore.

## Что это НЕ ДОКАЗЫВАЕТ

B263 не доказывает причинность в философском смысле, сознание, агентность или реальную внешнюю causal efficacy. Сейчас у нас learned interventional model внутри цифровой среды. Для сильной причинной претензии нужны внешние вмешательства, рандомизированные action assignments, скрытые конфаундеры, long-horizon behavioural tests и независимый environment holdout.

## Главные оставшиеся проблемы

1. Planning B262 пока не доказал behavioural advantage над greedy baseline.
2. Causal gain B263 пока мал; model distinguishability есть, но эффект ещё не глубокий.
3. Core policy path всё ещё не полностью перестроен вокруг learned causal model; B263 пока преимущественно causal observer/learner и intervention layer.
4. Долгосрочная причинность ещё не развернута на горизонтах десятки/сотни шагов.
5. Нет внешнего randomized action intervention harness.
6. Нет полноценного независимого environment benchmark, где агент должен физически/цифровым образом изменить мир и получить измеримую downstream benefit.
7. Файловый fsync gate из предыдущих проходов остаётся отдельной инфраструктурной проблемой среды и не смешивается с neural persistence round-trip.

## Следующий большой шаг

B264 должен замкнуть policy-to-consequence loop:

`causal model -> conservative action selection -> real action -> external/postcondition evidence -> observed consequence -> attribution -> policy update -> replay -> holdout`

Ключевой критерий B264: действие, выбранное с causal model, должно давать измеримо лучший outcome на unseen tasks, чем action-shuffled и greedy baselines. До появления этого результата нельзя считать агентность доказанной.
