# Neuro-Kurisu 34.75.0 — BIG PASS 101

## Skill Ecology + Meta-Skills

Этот проход продолжает BIG PASS 100 и переводит саморемонт навыков из простого журнала fallback-ов в ограниченную экосистему версий.

Добавлены variant lineage, holdout-валидация вариантов, promotion/rollback, мета-операции диагностики/выбора/сравнения/валидации/отката и перенос repair-событий в causal experience + unified learning.

Ограничения сохранены: нет произвольной генерации исполняемого кода, нет неограниченного branching, нет автоматического изменения личности/ценностей и нет утверждения о сознании.
