## Сравнение с B270

B270:
- связывает neural germinal substrate с self, autonomy и personality;
- нейронная память всё ещё в основном опирается на отдельные memory systems.

B271:
- добавляет learned sequence binding внутри neural substrate;
- даёт independent neural recall без sequence ledger;
- связывает reconstruction/self-prediction с internal goal generation;
- goal proposal получает bounded action influence;
- personality получает causal evidence уже от autobiographical neural loop.

## Что реально улучшилось

1. Уменьшена зависимость recall от внешней символьной memory-таблицы.
2. Появилась sequence-level neural learning, а не только per-step trait updates.
3. Появился внутренний goal pressure из памяти/self-prediction mismatch.
4. Усилилась связь neural memory → autonomy → personality.
5. Появился более строгий lesion-style conceptual boundary: удаляется sequence ledger, но learned weights остаются.

## Главные ограничения

1. Goal vocabulary всё ещё частично задан вручную.
2. Neural assemblies пока 16-мерные и маленькие.
3. Нет полноценной dendritic compartmental biophysics.
4. Нет доказанного долгого sequence recall на тысячах эпизодов с interference.
5. Нет доказательства semantic autobiographical recollection без внешнего semantic encoder.
6. Self prediction пока слабее reconstruction.
7. B271 не создаёт произвольные новые действия, а влияет на существующий candidate/action space.
8. Это не доказательство сознания.
