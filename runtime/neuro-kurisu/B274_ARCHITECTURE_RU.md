# B274 — Autonomous Skill Discovery Architecture

## Назначение
B274 добавляет самостоятельное открытие способов действия поверх уже существующей brain-chain B259–B273. Он не считает новый навык существующим только потому, что world-model его предсказал.

## Полный цикл
1. B273 формирует активную цель и план.
2. B262 генерирует альтернативные воображаемые планы и прогнозируемые последствия.
3. B274 выбирает ограниченный кандидат навыка и создаёт эксперимент.
4. Нейронное grounding проверяется через B269 assembly + B270 self latent + world latent.
5. Кандидат получает bounded real trial.
6. Независимый результат, prediction error, personality alignment и neural reliability объединяются в evidence.
7. Только после повторной положительной проверки кандидат может стать promoted skill.
8. Провал не продвигается; плохие кандидаты могут retire/rollback.
9. Проверенный навык может быть перенесён в новый goal-context только при отдельном transfer test.
10. Promotion/transfer и diagnostics переживают restart.

## Почему это сильнее B273
B273 уже умел порождать и переиспользовать планы внутри lifecycle цели, но его skill prototype напрямую происходил из успешного плана. B274 разделяет:

**воображение → эксперимент → независимую проверку → promotion**.

Таким образом, skill acquisition становится отдельным научно проверяемым процессом.

## Связь с нейронностью и личностью
Кандидат не оценивается только по reward. Его self-alignment, neural grounding и personality fit участвуют в promotion gate. Поэтому навык не должен проходить только потому, что он кратковременно полезен.

## Ограничения
Action space остаётся ограниченным текущим OrganismCore ActionKind. Воображаемый experiment всё ещё использует B262 world model; это не эквивалент физическому эксперименту во внешнем мире. Поэтому B274 пока доказывает цифровое self-directed skill discovery, а не общий skill invention.
