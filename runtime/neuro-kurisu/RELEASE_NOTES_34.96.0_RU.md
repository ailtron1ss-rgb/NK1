# Neuro-Kurisu 34.96.0 — BIG PASS 122

## Главный результат

Внедрён `PersonalCurriculumEngine` — связующий developmental слой между автобиографической историей, social development, целями и выбором того, чему организму стоит учиться дальше.

## Основные изменения

1. Learning threads формируются из уже существующих goal/outcome/autobiographical/social signals.
2. Для потока учитываются verified evidence, context diversity, retention, transfer, identity relevance и social relevance.
3. Активные цели получают исторический curriculum score.
4. Curriculum pressure передаётся в P67 Autonomous Goal Genesis и Meta-Developmental layer.
5. Recommended learning action может ограниченно участвовать в action arbitration.
6. Состояние сохраняется и проходит restart recovery.
7. Добавлены unit/core regression checks и diagnostics.

## Честная граница

Новая система не является доказательством сознания и не создаёт отдельную «личность поверх личности». Она усиливает причинную связь между жизненным опытом, развитием и будущим поведением.
