# Neuro-Kurisu Evolution 13 — P47 Temporal Memory Continuity

Большой шаг объединяет долговременную temporal memory, belief revision, причинно-связанные memory nodes и reflection consolidation. Состояние schema остаётся 48, новые поля optional.

Ключевой принцип: событие не равно памяти. Сначала появляется наблюдение, затем связь, затем belief/episode, затем консолидация. Ошибочные и конфликтующие убеждения должны оставаться видимыми как uncertainty, а не превращаться в тихое перезаписывание истории.
