# B282 — Predictive Global Workspace

B282 объединяет B280/B281 в общий предиктивный workspace. Это не утверждение о сознании, а инженерный нейронно-подобный слой с четырьмя главными свойствами:

1. Несколько областей конкурируют за coalition в общем latent workspace.
2. Победившая coalition создаёт глобальное состояние, которое доступно другим вычислительным путям.
3. Workspace предсказывает следующее глобальное состояние и получает delayed prediction error.
4. Глобальное состояние влияет на выбор действия, а outcome обучает prediction/action readout.

## Состав

- Sensorium
- Memory
- Association
- Self/Action
- Winner-take-all / top-2 coalition
- Global recurrent state
- Global future predictor
- Context projections: self/world/goal
- Action readout
- Ignition/dwell signal
- Coalition stability
- Area lesion
- Snapshot/migration

## Почему это сильнее B281

B281 предсказывает состояние одной области из другой. B282 создаёт единый глобальный latent и заставляет несколько областей конкурировать за доступ к нему. Это позволяет проверять не только локальную prediction accuracy, но и global-state prediction, coalition switching и causal workspace lesion.

## Ограничения

B282 не моделирует биофизический cortex, не является доказательством phenomenal consciousness и не заявляет, что ignition равен сознанию. Размер сети мал, нейроны упрощены, а workspace является инженерной рекуррентной моделью.
