# Release Notes B274

B274 добавляет самостоятельную лабораторию открытия навыков.

Новый цикл:

**goal → imagined plan → candidate skill → bounded real trial → independent evidence → promotion/rejection → transfer test → action bias**

Это интегрировано с B269 neural substrate, B270 self, B271 autobiographical memory, B272 endogenous goals, B273 goal lifecycle, personality and OrganismCore arbitration.

Ключевой принцип: предсказанное улучшение недостаточно для promotion.
