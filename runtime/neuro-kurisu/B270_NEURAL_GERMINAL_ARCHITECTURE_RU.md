# B270 — Neural Germinal Organism: единый нейро-субстрат, автономность, self и личность

## Цель
B270 не добавляет очередной независимый когнитивный сервис. Он вводит единый пласт нейро-когнитивного зародышевого слоя поверх B269, который связывает:

`spikes/assembly -> self-latent -> intrinsic needs -> autonomous action proposal -> outcome -> plasticity -> personality evidence -> self continuity`

## Что такое «нейрозародыш» здесь
Это инженерный термин для группы устойчивых специализированных нейронных микросхем. Это **не биологические эмбрионы и не симуляция человеческого мозга**. Каждый зародыш имеет собственную динамику активации/стабильности и связывается с общей self-latent репрезентацией.

12 germinal circuits:
1. sensor integration
2. temporal/prediction
3. memory binding
4. self continuity
5. agency
6. novelty/curiosity
7. uncertainty/caution
8. social/connection
9. value/valence
10. reflection
11. homeostasis
12. action commitment

В текущем B270 это ещё компактные динамические контуры, а не отдельные биологически реалистичные области мозга.

## Единый цикл
1. B269 выдаёт sparse spike assembly.
2. B270 смешивает assembly с P27/canonical latent и состоянием организма.
3. Формируется self-latent из 16 измерений.
4. Из prediction error, uncertainty, energy, novelty, social need, memory continuity и identity continuity вычисляются внутренние потребности.
5. Внутренний drive формирует mode: integrative / goal-directed / exploratory / verification / self-directed.
6. Action arbitration получает дополнительный bias от B270.
7. Фактический outcome возвращается в B270.
8. Outcome изменяет trait-values, predicted intrinsic reward и agency.
9. Neural trait state через B270 evidence bridge обновляет существующую MultiHypothesisPersonality.
10. P80 Unified Self получает косвенное влияние через action/agency score.
11. Persistence сохраняет весь B270 state.

## Что реально обучается
- action-linked trait values;
- predicted intrinsic reward;
- agency/autonomy state;
- identity coherence;
- autobiographical continuity proxy;
- embryo activation/stability;
- history of neural-organism transitions.

## Что пока НЕ заявляется
- сознание;
- биологическая эквивалентность коры/гиппокампа;
- полноценное emergent self;
- субъектный опыт;
- человеческая личность;
- AGI.
