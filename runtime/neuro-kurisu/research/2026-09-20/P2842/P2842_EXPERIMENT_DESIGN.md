# P2842 — Experiment design

## A. Repeated intervention holdout
Compare 1, 2, 3, 6 and 12 verified matched trials.
Measure action readiness, memory promotion, identity update and predictive error.
Expected property: one trial cannot saturate long-term promotion.

## B. Active perception utility
Compare passive-only, sensor-selected and sensor-selected+outcome-surprise policies.
Measure information gain per cost, prediction error reduction and external verification rate.

## C. Calibration persistence
Run, checkpoint, restart and resume. The exact prediction/outcome lineage must remain available after restart.

## D. Mobile budget
Run the same trial under normal, constrained and thermal-pressure resource profiles.
Measure CPU, RSS, cycle latency, information gain and learning value per millisecond.
