# B286 — Self Conflict & Continuity Architecture

B286 is a developmental identity layer above B284/B285. Its purpose is to make identity a causal structure rather than a single trait vector.

## Core loop
past self → present self → future self → value conflict → resolution → commitment → goal/action bias → outcome → revision

## Main mechanisms
- four future horizons (1/8/32/128)
- trait-specific future projections
- relationship-specific self state
- commitment memory
- conflict detection between present preferences, past commitments and desired future values
- slow identity revision
- replay / identity-anchor consolidation
- causal ablation
- personality evidence bridge

## What is genuinely neural-like
The module uses recurrent latent state, learned projections, activity-dependent plasticity, context-dependent conflict and ablation of learned projections. It is not a biophysical neuron simulation.

## Developmental rule
Ordinary experience updates latent state slowly. High-importance, high-conflict events can trigger a limited identity revision. This avoids personality churn every cycle.

## Expected role in Kurisu
B286 is intended to encode continuity claims such as: “what I was”, “what I am”, “what I want to become”, “what I promised”, and “what I refuse to lose”.
