Учить routing policy выбирать стратегию и compute budget по outcome, а не только по эвристикам.

Разнести autobiographical, self, value and goal traces в population code и проверить neural lesion/repair.

Связать short/medium/long latent predictions, uncertainty calibration и action-conditioned counterfactuals.

Experience → tension → candidate goal → competition → commitment → abandonment → successor goal.

## B491–B500 — Lifelong Holdout Lab
1k/5k/10k cycle tests, unseen contexts, memory saturation, recovery, rollback, ablation matrix и device benchmarks.
