# Neuro-Kurisu Master Roadmap — B347

## Priority 1 — Developmental predictive self-correction
`experience → prediction → action → outcome → calibration error → confidence update → epistemic arbitration → personality/self-model change`

Run this without manual personality injection.

## Priority 2 — Restart + unseen-context developmental holdout
Train prediction calibration, persist, restart, introduce a new context, and measure change in full action distribution. Require personality/self-model ablation as a causal control.

## Priority 3 — Long-horizon autonomy
Resolve current OrganismCore execution-cost bottlenecks and run 80–120+ closed-loop cycles with restart midway and holdout after learning.

## Priority 4 — Decision pipeline consolidation
Continue extracting decision/evidence/self-projection ownership from OrganismCore without creating parallel systems.

## Priority 5 — Embodiment
Prepare ARM64/Android/Termux runtime evidence. Host-only measurements remain HOST_ONLY.

## Priority 6 — Neural substrate
Strengthen shared causal coupling between plastic neural processes, predictive world model, memory, personality, and policy. Prefer changes that modify organism-level behaviour over isolated neural modules.

## Non-goals
- no cosmetic B-number proliferation;
- no consciousness claim from scalar metrics;
- no manual action forcing in autonomous holdouts;
- no PASS from timeout;
- no permanent hard-coded epistemic/exploration bonus for one action.
