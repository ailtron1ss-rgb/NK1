# BIG PASS 108 — Add / Not Add Matrix

| Элемент | Решение | Причина |
|---|---|---|
| Deterministic session schedule | ADD | фиксирует дизайн до outcome |
| Slot-level firewall | ADD | блокирует несоответствующие outcomes |
| Terminal session seal | ADD | исключает позднюю незаметную подмену набора данных |
| External evaluator source | ADD | отделяет оценку задачи от внутренних метрик |
| Trajectory state-hash ledger | ADD | позволяет потом сопоставить outcome с состоянием системы без превращения hash в score |
| Reproducibility utility | ADD | дешёвая автоматическая проверка критического свойства |
| Второй planner | NOT ADD | не повышает доказательность |
| Автоматическое вычисление task score из состояния | NOT ADD | circular validation |
| Consciousness score | NOT ADD | неизвестно, что именно он должен измерять |
| Автоматическое изменение личности по experimental score | NOT ADD | смешивает evidence и governance |
