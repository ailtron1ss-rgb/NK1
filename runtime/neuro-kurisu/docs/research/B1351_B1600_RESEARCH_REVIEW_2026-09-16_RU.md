# Research review B1351–B1600

Fresh 2026 directions incorporated:

- H-MEM: hierarchical memory with index-based routing instead of exhaustive similarity search. https://aclanthology.org/2026.eacl-long.15/
- LiCoMemory: temporal + hierarchy-aware agentic memory with reranking. https://aclanthology.org/2026.findings-acl.1835/
- HiGMem: event summaries as anchors to reduce retrieval bloat. https://aclanthology.org/2026.findings-acl.1690/
- GAM: decoupling rapid memory encoding from stable consolidation. https://aclanthology.org/2026.acl-long.1600/
- WorldEvolver: episodic + semantic world memory plus selective foresight. https://arxiv.org/abs/2606.30639
- Language Models Need Sleep: replay-based consolidation and synthetic dreaming/curriculum. https://arxiv.org/abs/2606.03979
- NeuroSynth: fast/slow continual-learning pathways inspired by hippocampal/cortical consolidation. https://arxiv.org/abs/2607.28663
- EvolvingAgent: planner-controller-reflector closed loop with a continual world model and self-evolving curriculum. https://arxiv.org/abs/2502.05907
- Emergence World: long-horizon evaluation over weeks/months, emphasizing drift and developmental dynamics. https://arxiv.org/abs/2606.08367

Adaptation principle: these results are architectural references, not evidence that Neuro-Kurisu matches their reported benchmarks. The implementation uses bounded, mobile-friendly approximations and validates them with project-specific tests.
