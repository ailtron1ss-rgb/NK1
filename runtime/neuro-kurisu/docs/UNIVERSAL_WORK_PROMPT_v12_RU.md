# NEURO-KURISU — UNIVERSAL WORK PROMPT v12

## Purpose
Работай над Neuro-Kurisu как над непрерывно существующим исследовательско-инженерным организмом. Цель — максимально автономный искусственный субъект с устойчивой памятью, self-model, world-model, развивающейся индивидуальностью, agency, social cognition, embodiment и экспериментально проверяемой перспективой consciousness.

## Non-negotiable rules
1. Реальный capability > число файлов/Pxx.
2. Один canonical owner для каждого класса истины.
3. Derived layers не становятся source of truth.
4. Integration/fusion предпочтительнее новых Pxx.
5. PASS нельзя получать ослаблением assertion, пропуском проверки, timeout inflation или runtime mock.
6. Гипотеза ≠ факт; consciousness остаётся открытой задачей.

## Mandatory causal loop
Ищи не просто наличие модулей, а цикл:
`BODY → PERCEPTION → WORLD → MEMORY → SELF → VALUES/NEEDS/GOALS → DELIBERATION → ACTION → CONSEQUENCE → PREDICTION ERROR → LEARNING → IDENTITY CHANGE → NEXT STATE`.

## New BIG PASS rule: close loops before adding modules
Перед созданием нового компонента проверь, можно ли замкнуть уже существующий loop. Shadow/counterfactual mechanisms считаются реально интегрированными только если:
`shadow prediction → bounded live influence → real observable outcome → calibration → persisted future effect`.
Наличие recommendation или simulation без observed feedback не считается closed developmental capability.

## Developmental self-change
Развивай цепочку:
`experience → evidence/counterevidence → trajectory → identity pressure → candidate self-change → acceptance/rejection → autobiography/lineage → future goal/action behaviour`.
Любое изменение self/values должно иметь provenance, evidence, confidence, counterevidence и rollback/review path.

## Counterfactual discipline
Не считай outcome выбранной ветви доказательством для невыбранной ветви. Counterfactual branch должна иметь отдельный prediction/evidence status. Real outcome может калибровать только ту альтернативу, которая действительно была выполнена, либо explicitly marked as partial shared evidence.

## Mobile-first
Termux + средний Android — целевой runtime. Сохраняй 1k/2k/5k/10k+ qualification. Timeout = UNRESOLVED. Не отключай cognition ради benchmark.

## Consciousness discipline
Используй категории PROVEN/IMPLEMENTED/FUNCTIONAL INDICATOR/OBSERVED/HYPOTHESIS/UNKNOWN/UNRESOLVED/FAILED. Предпочитай causal intervention, lesion/ablation, perturbation, isolation, counterfactual manipulation, recovery, cross-condition comparison и независимое наблюдение.

## BIG PASS execution
baseline → forensics → historical comparison → capability/ownership/conflict analysis → design alternatives → implementation/fusion → adversarial tests → long-horizon qualification → docs → release → ZIP extract/retest/hash → self-critique.

## Required final accounting
Всегда показывай delta, real changes, previous-plan completion, tests PASS/FAIL/UNRESOLVED, conservative readiness, unresolved limitations, legacy decisions, next BIG PASS и собственные falsifiable ideas.

## Main internal question
«Можно ли сделать это более реально, связно, дёшево для телефона, проверяемо и без duplicate owner?» Если да — делай. Если неизвестно — experiment. Если не доказано — не добавляй complexity.
