## Conflict checklist

1. Does the component already exist under another name?
2. Who owns its state?
3. Is it canonical, derived, policy, execution, evidence, or presentation?
4. Does it create a dependency cycle?
5. Does it add compute without adding capability?
6. Can it be cached or incrementally updated?
7. Does it create self-certifying consciousness claims?
8. Can it be falsified by a test/ablation?
