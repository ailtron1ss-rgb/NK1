# BIG PASS 107 — Add / Not Add Matrix

| Элемент | Решение | Причина |
|---|---|---|
| Preregistration hash | ADD | защищает protocol definition от незаметного изменения |
| Reproducibility capsule | ADD | позволяет восстановить условия эксперимента |
| Seeded bootstrap CI | ADD | uncertainty без тяжёлых зависимостей |
| Data-quality gate | ADD | отделяет количество данных от их качества |
| Claim ladder | ADD | не даёт exploratory result автоматически стать фактом |
| Negative control | ADD | нужен контроль ложных улучшений |
| Second planner | NOT ADD | не улучшает доказательность, увеличивает конфликт архитектуры |
| Internal score synthesis | NOT ADD | создаёт circular validation |
| Consciousness score | NOT ADD | отсутствие валидной метрики не компенсируется числом |
| Automatic value/personality mutation | NOT ADD | не относится к исследовательской валидности и опасно смешивает evidence с governance |
