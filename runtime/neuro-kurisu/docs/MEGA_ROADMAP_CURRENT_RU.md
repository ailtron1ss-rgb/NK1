## P35 — ✅ завершено
Практический результат: persistent semantic world graph, modality provenance, spatial self model, host/body state, body-aware affordances и runtime/API integration. Ограничение: native semantic vision/audio пока не реализованы; P35 предоставляет честный adapter/scaffold.

## P36 — автономное саморазвитие ✅ архитектурно усилено
Практический результат: организм сам выбирает developmental focus, оценивает D-VOI и стоимость обучения, может инвестировать/отложить/восстановиться, формирует гипотезу и campaign plan. Sandbox остаётся preview-only; mastery/action policy изменяются только после внешнего delayed/holdout evidence. P36 не выполняет опасные внешние действия; sandbox является preview-only, а реальные developmental changes допускаются только через внешний evidence gate.

## P37 — Semantic World & Real Perception
Настоящий semantic vision/audio backend, learned multimodal representation, richer spatial/body model, multi-step latent world prediction и real-world calibrated perception.

## P38 — Autonomous Causal Research
Самостоятельное формирование гипотез, выбор control/treatment, sandbox execution, replication, statistical analysis, learning, rollback и self-authored developmental curriculum.

## P39+ — непрерывная искусственная жизнь
Недели/месяцы, реальный POCO gate, device migration, identity-preserving continuation/branching, autonomous maintenance, отношения, embodied humanoid path и долгосрочные исследования consciousness.

## Сквозные обязательные gates
1. Functional capability должна иметь реальный runtime path.
2. Claims должны иметь evidence level.
3. Learning должен проходить holdout/retention/rollback проверки.
4. Безопасность действий отделяется от свободы внутреннего состояния.
5. Phone-ready нельзя объявлять device-verified без фактического POCO test.
6. Functional consciousness-like properties не объявляются доказательством subjective experience.
