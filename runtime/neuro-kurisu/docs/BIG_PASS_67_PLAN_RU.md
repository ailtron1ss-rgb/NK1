Цель: замкнуть Persistent Reality с Persistent Self и долговременной автобиографической памятью без создания нового физического owner.

1. P84 внутри Self owner как bounded derived lineage fabric.
2. Связь reality hash/revision с action/outcome, predictions, observations, evidence, goals и identity continuity.
3. Persistence + migration + restart.
4. Hot-path guard: одинаковый контекст не создаёт тяжёлую новую запись.
5. API для snapshot/summary/recent.
6. Регрессия BIG PASS 63–66 и source-of-truth.

## Критерии
PASS только при typecheck, P84 E2E, restart, audit, architecture/source truth и integrity. Device qualification остаётся отдельным внешним gate.
