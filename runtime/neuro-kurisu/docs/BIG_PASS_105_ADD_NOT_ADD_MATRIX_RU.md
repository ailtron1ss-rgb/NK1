# BIG PASS 105 — ADD / NOT-ADD

| Добавить | Почему |
|---|---|
| Experimental protocol | Делает условия вывода явными |
| Matched/confirmatory gate | Не позволяет выдавать несопоставимые данные за paired evidence |
| Evidence ledger | Сохраняет provenance от replay до независимой проверки |
| Transfer matrix | Показывает направление positive/negative transfer |
| Transfer inference gate | Требует holdout и контекстного разнообразия |
| Memory-skill evidence query | Связывает память с procedural layer без второго хранилища |

| Не добавлять | Причина |
|---|---|
| Вторую memory system | Дублирование и расслоение истины |
| Второй planner | Архитектурная конкуренция |
| Автогенерацию runtime-кода | Непредсказуемость и усложнение safety boundary |
| Consciousness score | Нет эмпирического основания |
| Ручную подгонку benchmark result | Нарушает исследовательскую честность |
