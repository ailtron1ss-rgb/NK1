# WorkPass571 — стабилизация контекста извлечения памяти

**Дата:** 2026-10-27  
**Ветка:** `feature/memory-query-context-workpass571-2026-10-27`  
**Область:** канонический MemoryOS2 и контекстная маршрутизация retrieval.

## Найденная проблема

В `MemoryOS2.retrieve()` признаки `contextTemporal` и `contextCausal` частично выводились из накопительных счётчиков `semanticQueries` и `linkUpdates`. Поэтому история использования влияла на смысл следующего запроса: после достаточного количества обычных обращений запрос без временных маркеров получал ненулевую временную оценку; накопленные изменения ссылок аналогично могли искусственно повышать причинный контекст.

Эти счётчики — телеметрия общей истории, а не свидетельство намерения текущего запроса. Их использование как контекстных признаков смешивало долговременную статистику с сигналом текущей задачи и могло переключать `AdaptiveMemoryPolicy`, а также влиять на ранжирование связей.

## Изменение

- Контекст извлечения теперь вычисляется из текущей формулировки запроса и явного temporal mode.
- Причинный контекст включается по причинному намерению/лексическим маркерам, временной — по явному временному режиму, эпизодическому намерению или временным маркерам.
- Накопительные счётчики продолжают существовать как статистика, но больше не используются как скрытая подмена смысла запроса.
- Добавлена регрессия на 80 последовательных общих retrieval-вызовах, затем на отдельных временном и причинном вопросах; тест подключён к `test:rebuild-recovered`.

## Следующие проходы

1. Свести независимые ветки retrieval/CLI и causal-replay без переноса больших расходящихся деревьев целиком.
2. Сравнить retrieval на неизменяемом размеченном holdout с baseline/candidate, раздельно по английским и русским запросам, temporal updates и abstention.
3. После независимого положительного `recallDelta`, сохранения MRR/abstention и учёта стоимости включить изменение в следующую release-сборку.

## Статус достоверности

Файлы и привязки записаны в Git-ветку WorkPass571. Регрессия в этом проходе не запускалась; прохождение теста не заявляется. Release ZIP не обновлён. Эта работа исправляет определённую причину нестабильности контекстной маршрутизации, но сама по себе не доказывает улучшение качества извлечения на независимых данных или готовность всего NK1 к production.
