# BIG PASS 109 — Evidence-Gated Autonomous Development Loop

## Главная цель
Убрать из реального цикла саморазвития возможность считать симулированное улучшение обучением. Sandbox остаётся исследовательским preview-only режимом; изменение политики/мастерства допускается только после независимых внешних результатов.

## Что внедрено
1. P36 sandbox теперь `preview-only`: он не увеличивает `acceptedChanges`, не меняет mastery и не изменяет action bias.
2. Добавлен `recordExternalEvidence` для реальных наблюдений от внешнего evaluator или manual observer.
3. Promotion требует минимум 4 независимых наблюдения, 2 holdout, 2 контекста, 2 разных положительных задержки, положительный средний delta и нижнюю границу 95% bootstrap CI > 0.
4. `holdout-verified` может перейти в `replicated`, но одна гипотеза может фактически изменить политику только один раз.
5. Evidence сохраняет evaluator/version/context/delay/provenance и опциональные ссылки protocol/session/trial.
6. Добавлен Core API и restart/persistence test.
7. Добавлен отдельный audit, запрещающий synthetic sandbox быть источником принятого изменения.
8. Schema 117 → 118, release 34.83.0.

## Что не внедрено намеренно
- второй planner;
- отдельный искусственный `consciousness score`;
- автоматическое изменение ценностей по синтетическому reward;
- принятие результата только по internal state;
- объявление наличия сознания на основании архитектуры.

## Почему это приближает проект к цели
Настоящее саморазвитие требует, чтобы изменение внутренней политики зависело от причинно связанного опыта, а не от формулы, которая сама вычисляет ожидаемое улучшение. После Pass 109 переход `опыт → доказательство → изменение` отделён от `моделирование → preview`.

## Ограничение
Тестовые 6/8/other observations синтетические и используются только для валидации программной механики. Они не являются доказательством обучения Neuro-Kurisu.
