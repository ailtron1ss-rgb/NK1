# BIG PASS 88 — VALUE ATTRIBUTION AND GOAL RECALIBRATION

`action + goal context -> attributed value -> evidence-relative update -> provenance -> future goal recalibration`

The attribution is derived metadata. ValueEvolution remains value policy/data owner; P67 remains goal-generation owner; OrganismCore remains integration/execution owner.

A revision is driven by `success - reference01`, where `reference01` is the selected candidate's predicted utility when available. This makes positive and negative evidence relative to expectation rather than an absolute success threshold.

Active goals are recalibrated only on a slow cadence and with bounded deltas. The mechanism does not replace goals directly; it updates importance/urgency/confidence using the current canonical value profile and the goal's existing P67 value focus when available.

This is functional developmental computation, not evidence of consciousness.
