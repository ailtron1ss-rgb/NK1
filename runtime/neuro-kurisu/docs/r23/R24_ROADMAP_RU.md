# R24 roadmap

1. Causal eviction-regret: paired retained-control vs evicted-memory experiments with delayed query outcomes and explicit counterfactual accounting.
2. Extend world-model sequence planning from 3 to 5–8 actions with richer held-out counterfactual regret and terminal-state error.
3. Expand the long-memory battery toward the five LongMemEval-V2 ability families while retaining a mobile-sized internal version.
4. Compare the canonical neural stack against the R23 bounded recurrent lane using matched tasks and lesion/ablation measurements.
5. Run 1000–5000 cycle endurance on the real Android/Termux target and capture RSS, latency, GC, checkpoint and thermal effects.
6. Increase critical runtime operation evidence coverage from the current frontier toward 100–200 verified operations without mass-generated evidence.
7. Keep static semantic coverage honest; improve it by instrumenting actual critical operations rather than relaxing the verifier.
8. Revisit memory byte budgets under real mobile RAM/thermal observations and make the budget adaptive to host pressure only through the resource-governance boundary.
