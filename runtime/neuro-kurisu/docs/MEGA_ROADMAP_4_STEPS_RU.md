## Два следующих гигантских этапа

### Giant Step A — P26 Neural Perception + Learned World Foundation

Настоящее semantic vision/audio, learned temporal world model, executable counterfactual sandbox, cross-modal latent state и mobile inference budgets.

### Giant Step B — P27 Autonomous Research Organism + Longitudinal Self-Evolution

Самостоятельное планирование исследований, self-ablation, model ecology, memory thermodynamics, energy-to-information economy, long-lived identity и реальные 30-дневные device tests.

## Жёсткие правила

1. Новый механизм обязан иметь baseline, observable metric и failure path.
2. Сильное утверждение требует evidence level не ниже controlled.
3. Longitudinal capability не подтверждается единичным тестом.
4. Device-verified означает физический device-side тест.
5. Deterministic scaffold не называется semantic/learned без соответствующего backend.
