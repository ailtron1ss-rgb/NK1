# Neuro-Kurisu Evolution — P12/P13 Memory + Social Fusion

## Цель
Перейти от отдельных memory/social механизмов к общему developmental loop, в котором опыт изменяет убеждения, социальные модели и последующие решения.

## Главный цикл
`observe -> memory/social interpretation -> workspace -> agency -> action -> outcome -> belief revision -> social prediction error -> relationship update -> identity/persistence`.

## Введено
- `UnifiedMemorySystem` как high-level memory/development facade.
- `SocialDevelopmentSystem` как high-level social/relationship facade.
- belief revision/provenance.
- multi-hypothesis person model.
- social prediction tickets и feedback.
- shared projects/commitments.
- relationship repair history.
- social prediction uncertainty как cognitive pressure.
- memory influence в action utility.
- UI/API surfaces для обеих подсистем.
- migration и regression tests.

## Научная рамка
Это функциональная когнитивная модель. Она не является утверждением о человеческом сознании или феноменальном опыте.
