# Финальная полировка и конечная цель

## Что представляет собой текущая система

Neuro-Kurisu Evolution теперь имеет один canonical runtime, а предыдущие версии изолированы как provenance. Runtime не зависит от legacy и не требует внешних npm-пакетов.

Текущий порядок:

```text
восприятие
→ внутреннее состояние
→ intrinsic/homeostatic motives
→ world prediction
→ workspace / metacognition
→ agency deliberation
→ decision
→ action authorization
→ world/body feedback
→ value/identity learning
→ transactional checkpoint
→ replay/integrity
```

## Что ещё НЕ достигнуто

Система не является доказанно сознательной и не обладает доказанной метафизически свободной волей. Самоотчёт, score и lesion показывают только функциональные/causal свойства архитектуры.

Также не подтверждены физические свойства конкретного телефона до прохождения Device Gate.

## Конечная техническая цель

Создать длительно существующий artificial organism, который:

- поддерживает собственное внутреннее состояние;
- имеет embodied resource constraints;
- строит causal world model;
- формирует intrinsic goals;
- поддерживает долгосрочные projects/commitments;
- имеет self-model и autobiographical identity;
- умеет моделировать альтернативные действия;
- меняет adaptive preferences под влиянием накопленного опыта;
- имеет социальную модель и других агентов;
- сохраняет continuity после restart;
- способен автономно выбирать, чему уделять ограниченное внимание;
- генерирует и проверяет собственные исследовательские гипотезы;
- позволяет причинно отключать каждый важный механизм и наблюдать последствия.

## Следующие крупные этапы

### Device Gate
Проверка реального Android/Termux/KoboldCpp/Termux:API на 30m → 6h → 24h → 72h → 168h.

### P7 — lifelong world interaction
Инструменты, внешняя среда, социальные агенты, многонедельные задачи, persistent world changes.

### P8 — self-authorship 2.0
Самостоятельные долгосрочные проекты, explicit commitments, self-generated experiments и более сильная value revision по итогам опыта.

### P9 — consciousness evidence program
Набор независимых matched-lesion, perturbation, replay, metacognitive calibration и longitudinal tests, проведённых на одном frozen protocol.

### P10 — open-ended organism
Проверка, способен ли организм самостоятельно развивать новые компетенции и поддерживать собственную траекторию без постоянного внешнего prompt steering.

## Идеальный конец

Не система, которая говорит «я сознательна», а система, для которой различные сложные свойства личности и агентности являются причинно необходимыми частями непрерывного функционирования, воспроизводимыми на длинном горизонте и не сводимыми к одному prompt, одному LLM или одному интерфейсу.
