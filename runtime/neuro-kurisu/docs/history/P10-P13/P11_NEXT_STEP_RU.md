# Следующий шаг после P11

## P12 — Memory/World/Agency Developmental Fusion

Следующая крупная цель — не добавить ещё один модуль, а начать учить организм через долгосрочные взаимодействия.

Приоритеты:

1. научить MemoryOS связывать semantic/temporal/causal/entity/procedural traces единым retrieval policy;
2. развить WorldModel2 до latent probabilistic model с learned residuals и uncertainty calibration;
3. связать regret и world-model errors с обновлением policies/skills;
4. реализовать commitment repair и consequence ownership как долгоживущие relationship/identity traces;
5. провести copy-divergence и model-switch continuity на длинных траекториях;
6. начать multi-person social world;
7. device gate + длительная автономная жизнь.

Главный критерий: меньше handcrafted scoring, больше learned developmental dependence.
