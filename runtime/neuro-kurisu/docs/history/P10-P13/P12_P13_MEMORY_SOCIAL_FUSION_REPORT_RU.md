# Neuro-Kurisu Evolution 5.2.0 — P12/P13 Memory + Social Fusion

## Назначение
Эта версия объединяет память и социальное развитие в одном developmental loop. Цель — чтобы опыт менял не только записи, но и последующие belief, social predictions, relationship state и выбор действий.

## Главный цикл
`observe -> retrieve/encode -> social prediction -> workspace -> agency -> action -> outcome -> belief revision -> social prediction error -> relationship update -> identity/persistence`.

## Новые компоненты
- UnifiedMemorySystem: belief records, provenance, revision history, retrieval history, development statistics.
- SocialDevelopmentSystem: PersonModel, multi-hypothesis intent, social prediction tickets, trust/predictability, relational self, shared projects, commitments and repair history.
- Social prediction error -> cognitive pressure/action utility.
- Memory belief influence -> action utility.
- Persistent schema 16 + migration.
- UI/API surfaces for unified memory and social development.

## Что не утверждается
Компоненты являются функциональными моделями. Эта версия не заявляет феноменального сознания, qualia или метафизически свободной воли.
