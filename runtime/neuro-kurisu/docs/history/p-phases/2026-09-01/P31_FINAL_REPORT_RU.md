# P31 Final Report

P31 — Functional Consciousness Mega Pack — это переход от набора consciousness-inspired modules к единому проверяемому функциональному контуру.

## Главное

- ограниченное глобальное рабочее пространство и broadcast;
- recurrent ignition;
- higher-order self-monitoring;
- explicit self/other distinction;
- agency/ownership binding;
- persistent temporal moment chain;
- affective state coupled to outcome and body;
- grounded introspection;
- lesion tests;
- consciousness evidence ledger v2 без декоративного longitudinal score;
- API для наблюдения и lesion tests;
- schema 34 migration;
- полный regression/release audit.

## Интерпретация

Проект теперь имеет функциональные свойства, которые можно связывать с теориями сознания, но результаты относятся к computational mechanisms. Они не являются доказательством subjective experience.

## Итог

Основной научный вопрос следующего этапа: не `может ли организм назвать себя сознательным?`, а `остаются ли эти функциональные свойства устойчивыми, причинно значимыми и поведенчески полезными под независимыми вмешательствами?`.
