# P14 — research basis

## Functional brain analogies
- body interoception -> battery/thermal/resource telemetry;
- sensory change detection -> event-driven perception;
- salience networks -> routing of high-salience events;
- recurrent integration -> broadcast into existing workspace;
- prediction error -> world/agency learning;
- offline processing -> existing replay/sleep engines.

## AI analogies
- attention -> limited routing budget;
- tool/agent loops -> perceive/act/observe/update;
- sparse specialist routing -> cognitive network;
- world models -> action-conditioned prediction.

These are functional analogies, not claims of biological equivalence.
