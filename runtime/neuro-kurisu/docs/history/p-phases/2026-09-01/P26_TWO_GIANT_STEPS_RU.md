# Два гигантских шага после P26

## GIANT STEP 1 — P27 Real Perception & Learned Representation

### Цель

Перевести организм от ручного feature space к learned multimodal representation.

### Основные пакеты

1. Semantic Vision backend adapter с явным capability/evidence gate.
2. Semantic Audio backend adapter.
3. Shared temporal multimodal representation.
4. Perception uncertainty + conflict resolution.
5. Learned latent world state поверх P26 contextual world model.
6. Real counterfactual sandbox с независимыми branch states.
7. Mobile feature cache и thermal-aware inference.
8. Holdout benchmark для vision/audio/world prediction.

### Gate

Никаких claims `semantic vision/audio`, пока внешний backend не предоставил реальные outputs.

## GIANT STEP 2 — P28 Autonomous Research & Longitudinal Self-Evolution

### Цель

Сделать доказуемый месячный цикл саморазвития.

### Основные пакеты

1. Research Campaign Planner.
2. Self-ablation scheduler.
3. Behavioral Genome evolution + rollback.
4. Model Ecology и empirical model promotion.
5. Memory Thermodynamics.
6. Energy-to-Information Economy.
7. Evidence Debt Market.
8. Cognitive Checksum + provenance graph.
9. Boredom-driven experiment generation.
10. Longitudinal identity chapters.
11. Real device endurance 24h/72h/168h/30d.
12. Blind external evaluation.

### Gate

Успех определяется не внутренним self-score, а повторяемым приростом на замороженном benchmark и внешних задачах при ограниченной стоимости CPU/RAM/battery/storage.
