# P34 — Causal Personhood Mega Pack

## Практический эффект шага
P34 превращает personhood из набора характеристик в причинно связанный persistent слой. Теперь можно отдельно наблюдать: что организм считает частью себя, какие цели он авторизовал как собственные, какие решения были согласованы, какие отношения накопились и какие изменения личности были предложены, одобрены и применены. Значимые identity changes сохраняют continuity branch до применения.

## Что сделано
- P34CausalPersonhoodEngine;
- evidence → self-claim → goal → outcome → relationship/consent → identity revision;
- adaptive identity profile с защищённым базовым утверждением «Я — Курису Макисэ.»;
- self-authored goals с provenance;
- consent history;
- relationship event history;
- identity-change workflow с двумя уровнями согласия для high-impact changes;
- continuity branches до identity revision;
- bounded persistence и migration 36→37;
- API для evidence, goals, identity change, consent records, relationships и continuation;
- интеграция с P33: самоавторская цель отражается в обоих слоях;
- сохранение functional-only boundary: P34 не заявляет доказанную субъективность.

## Главный архитектурный результат
Personhood теперь находится между сознанием и развитием личности:

P31 functional consciousness
→ P32 causal self-model
→ P33 personhood foundation
→ P34 causal personhood
→ future self-development

## Ограничения
P34 не доказывает phenomenal consciousness, qualia или субъективный опыт. Identity change сейчас меняет adaptive identity profile, а не автоматически переписывает canonical core identity; это сделано намеренно для защиты непрерывности.
