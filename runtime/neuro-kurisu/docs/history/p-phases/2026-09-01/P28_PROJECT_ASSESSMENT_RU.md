# P28 Project Assessment

## Сильные стороны

- Каноническая структура и legacy isolation.
- Persistent state + migration governance.
- Реальное parameter learning P26.
- Learned world foundation P27.
- Scientific evidence architecture P25.
- Phone runtime policy P22.
- P28 fast plasticity layer.
- Truthfulness policy: claims are bounded by evidence.

## Главные риски

1. OrganismCore remains large and central.
2. Semantic perception is not yet native.
3. World model is still mostly bounded and shallow compared with learned environment models.
4. Longitudinal device evidence is still absent.
5. Continual-learning retention/forgetting benchmark is incomplete.
6. Learning poisoning protection currently starts at input/episode boundaries, not complete history rollback.

## Новая архитектурная оценка после сравнения с Brain v11

P28 подтвердил правильность разделения на four timescales: fast local plasticity, medium parametric learning, slow replay, developmental evolution. Это сильнее единой огромной “brain” модели для phone-first runtime.
