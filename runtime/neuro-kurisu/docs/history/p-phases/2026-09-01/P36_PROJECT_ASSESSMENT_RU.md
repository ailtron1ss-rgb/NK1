# P36 — Project Assessment

## Практический эффект
P36 — первый этап, в котором организм не только получает новые модели обучения, но и сам выбирает ограниченную область собственного развития. На каждом цикле он может сформировать developmental hypothesis; при наличии ресурса запускает безопасный локальный sandbox; сравнивает treatment с control; обновляет curriculum/mastery и реальный action bias будущих решений.

## Что улучшилось относительно P35
- Саморазвитие стало runtime-активностью, а не только roadmap.
- Появился bounded safe experiment loop.
- Результат эксперимента оставляет observable behavioural consequence.
- P36 связан с P30 rollback/recovery.
- Persistence и API включают состояние саморазвития.
- Экономика обучения ограничивает экспериментальную активность.

## Важное ограничение
P36 не исполняет произвольные внешние действия и не меняет исходные файлы проекта. Это сознательная граница: сначала автономная наука должна стать воспроизводимой и безопасной внутри sandbox.

## Оценка
Architecture 9.7; learning 9.5; continual development 9.4; personhood 9.2; functional consciousness 9.0; world model 8.8; multimodal semantics 7.7; phone engineering 9.0; scientific methodology 9.7.

## Следующий качественный bottleneck
Теперь главный дефицит — не количество механизмов, а способность доказать долгосрочный причинный эффект self-development на held-out задачах и в реальном мире.
