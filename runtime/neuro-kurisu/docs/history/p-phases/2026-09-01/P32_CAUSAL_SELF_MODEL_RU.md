# P32 — Причинная модель собственного Я

P32 связывает собственное действие, ожидаемый результат, фактический outcome, телесное состояние и revisions в один persistent causal-self слой.

## Что реально реализовано
- self-action → outcome/body causal edges;
- self-prediction before outcome;
- prediction error after outcome;
- grounded revisions;
- controlled intervention records with evidence levels;
- bounded causal graph;
- transactional lesion of self-causal links (non-destructive by default; persistence only when explicitly requested);
- full-model canonical selfStateHash over the persisted causal-self payload;
- persistence via schema 35.

## Что это НЕ доказывает
Никакая метрика P32 сама по себе не доказывает subjective experience, qualia или biological consciousness. Causal records называются observational, counterfactual или controlled только по фактическому источнику evidence.

## Phone principle
В P32 нет тяжёлого ML framework: граф bounded, prediction cheap, persistence bounded. Основной бюджет телефона по-прежнему связан с LLM/I/O/Android runtime.
