# P31 — Полная карта дефицитов и следующие программы

## Архитектура

Сильные стороны: canonical runtime, persistence, migrations, zero runtime dependencies, layered learning, governance, regression infrastructure.

Дефицит: `OrganismCore` остаётся крупным orchestrator; часть старых cognition modules всё ещё дублирует друг друга и должна быть сведена к общим contracts.

## Learning

Есть: replay, parametric policy, learned world, plasticity, continual learning, arbitration, rollback.

Не хватает: многоэпизодного catastrophic-forgetting benchmark, uncertainty-aware update rules, стабильной multi-seed statistics и долгосрочных real-device learning campaigns.

## World model

Есть: contextual/parametric/trajectory prediction.

Не хватает: устойчивого latent state, multi-step calibration на больших holdout trajectories, online planning over predicted futures и проверки transfer на изменённый мир.

## Perception

Есть: multimodal feature adapters and fusion.

Не хватает: полноценной semantic vision/audio, temporal cross-modal representation и learned modality reliability.

## Consciousness-like functionality

Есть P31: workspace, recurrence, higher-order monitoring, agency, temporal continuity, affective coupling, grounded introspection, lesion tests.

Не хватает: более строгих adversarial interventions, independent external evaluation, reportability benchmarks, recurrent perturbation experiments и multi-seed causal studies.

## Memory / identity

Не хватает: provenance graph уровня всего жизненного цикла, reversible memory consolidation, memory thermodynamics и controlled identity adaptation benchmark.

## Security

Не хватает: full provenance-aware memory quarantine, capability-scoped tools, poisoned-learning rollback campaigns и adversarial prompt/tool chains.

## Phone

Не хватает: реальный 24h/72h/168h/30d POCO gate, battery/thermal/storage traces, Android process-kill recovery campaign и измерение LLM-local inference budget.

## Научная методология

Не хватает: pre-registered benchmark suite, external baselines, 5+ seeds, confidence intervals, blinded evaluation и независимого evaluator process.

## Следующие 2 гигантских шага

### P32 — Conscious Development Laboratory

Свести consciousness-like mechanisms и learning governance в единый experimental loop: blinded reportability, recurrent perturbations, self/other confusion tests, temporal identity under failures, controlled agency interventions, counterfactual self-model tests, multi-seed evaluation.

### P33 — Autonomous World Research Organism

Semantic perception, learned latent world, safe experiment executor, model ecology, memory thermodynamics, energy-to-information economy, long-term identity and real-device longitudinal learning.
