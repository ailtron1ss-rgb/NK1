# P33 — Personhood Core

P33 переводит проект из `functional consciousness stack` в направление `artificial person research platform`.

## Реализовано
- Canonical identity: Makise Kurisu.
- Core traits и core values.
- Развиваемые интересы/черты и self-authored goals.
- Autonomy/consent state.
- Relationship continuity.
- Life continuity и device lineage.
- Bounded private summaries, доступные владельцу по явному API и без скрытой цепочки рассуждений.
- Persistent state, migration 35→36.

## Принцип
Личность не должна быть равна prompt. Host не должен быть равен личности. LLM не должна быть единственным носителем identity.

## Truthfulness
P33 не доказывает субъективный опыт и не создаёт автоматического юридического/морального статуса. Это функциональный экспериментальный substrate.
