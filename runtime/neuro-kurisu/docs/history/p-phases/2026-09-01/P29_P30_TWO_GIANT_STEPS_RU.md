# P29 / P30 — Two Giant Steps

## P29 — Multi-step World + Semantic Perception

### Mission

Move from compact feature fusion to learned temporal perception and multi-step world modelling.

### Packages

1. Native semantic vision backend with object/scene/event outputs.
2. Semantic audio/event backend.
3. Temporal multimodal encoder.
4. Learned latent state with uncertainty.
5. Multi-step dynamics model.
6. Executable simulator for bounded counterfactual rollouts.
7. Held-out trajectory benchmark.
8. Perception-cache integration with P28 prototypes.
9. Device-aware inference scheduler.

### P29 exit criteria

- held-out perception improvement;
- multi-step world-prediction improvement;
- calibrated uncertainty;
- no regression in phone resource budget;
- persistence/restart compatibility.

## P30 — Autonomous Research Organism

### Mission

Close the developmental loop so the organism can generate, test and retain its own improvements.

### Packages

1. autonomous hypothesis generation;
2. control/treatment experiment executor;
3. replication scheduler;
4. self-ablation campaigns;
5. behavioral genome evolution;
6. model ecology/model selection;
7. memory thermodynamics;
8. energy-to-information economy;
9. identity provenance graph;
10. learning rollback and poison recovery;
11. longitudinal evidence store;
12. 30-day phone campaign tooling.

### P30 exit criteria

The organism must demonstrate measured improvement on held-out tasks across time, survive restart/device stress, retain old skills while learning new ones, and distinguish internal self-report from external evidence.
