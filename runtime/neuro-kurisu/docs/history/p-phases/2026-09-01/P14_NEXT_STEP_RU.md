# P14 Next Step

## P15 — Sleep, Skills and Lifelong Learning

Основная цель: превратить накопленный опыт в долговременное изменение способности организма действовать.

Приоритет:
1. multi-timescale replay;
2. procedural skill promotion/demotion;
3. reconsolidation and forgetting;
4. sleep phases;
5. micro-dreams -> full offline dream simulation;
6. long-horizon project resumption;
7. device-aware learning budget.

P15 не должен снова раздувать количество coordinator-модулей. Все механизмы должны входить в единый developmental loop и иметь ablation/recovery test.
