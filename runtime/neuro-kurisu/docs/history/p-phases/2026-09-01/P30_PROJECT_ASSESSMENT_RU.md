## Самое сильное
1. Многовременной learning stack: P23/P26/P27/P28/P29/P30.

## Главный риск
Complexity management. Чем больше learning modules, тем опаснее их взаимное влияние. P30 начинает решать это через gate/provenance, но следующий шаг должен измерить causal contribution каждого слоя.
