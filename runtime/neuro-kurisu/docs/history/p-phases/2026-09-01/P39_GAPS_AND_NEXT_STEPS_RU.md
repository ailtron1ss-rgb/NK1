# P39 — Что ещё не хватает

## Закрыто в P39
- единый lifecycle state;
- sleep/recovery bookkeeping;
- continuity gaps;
- host lineage;
- resource stress accounting;
- lifecycle-to-action coupling;
- persistent migration;
- server observability.

## Не закрыто
1. Реальная physical device campaign 24h/72h/168h/30d+.
2. Действительно semantic vision/audio backends.
3. Реальный multi-branch external causal sandbox.
4. Independent evaluator и multi-seed statistics.
5. Identity-preserving transfer между физическими устройствами.
6. Полностью автономный безопасный research lifecycle.
7. Phenomenal consciousness — неизвестно.

## Следующий крупный переход
P40 должен объединить lifecycle с long-horizon world/body simulation, semantic perception, sleep/consolidation scheduling и автономным экспериментальным планированием так, чтобы качество долгой жизни оценивалось по траектории, а не по одному snapshot.
