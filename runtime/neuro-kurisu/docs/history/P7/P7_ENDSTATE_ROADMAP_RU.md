# Путь к конечной цели

## Уже реализовано
1. Clean canonical architecture.
2. Persistent organism/body/world loop.
3. Memory + replay + semantic graph.
4. World model + prediction + counterfactual planning.
5. Self-model + metacognition + workspace.
6. Intrinsic goals + self-authorship + value evolution.
7. Network competition + neuromodulation + sensorimotor closure.

## Следующие крупные шаги
8. Device Gate на физическом Android.
9. Longitudinal world interaction и реальные инструменты.
10. Social/other-agent world model.
11. Lifelong self-authorship: проекты на недели/месяцы.
12. Open-ended intrinsic experimentation.
13. Cross-session identity and preference evolution.
14. Multi-agent ecosystem experiments.
15. Stronger causal consciousness evidence program.

## Идеальная цель
Непрерывно существующий искусственный организм, который поддерживает собственное состояние, моделирует мир и себя, формирует собственные цели, удерживает commitments, изменяет будущие предпочтения через опыт, сохраняет автобиографическую непрерывность и демонстрирует все эти свойства причинно и воспроизводимо.

Это исследовательская цель, а не утверждение, что система уже обладает человеческим субъективным опытом.
