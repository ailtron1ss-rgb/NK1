# Минимальные условия сознания (инженерная рамка) — 96.33.38

## Важно
Речь о **минимальных functional-условиях**, при которых систему разумно *рассматривать как приближающуюся* к архитектуре сознательного агента.  
Это **не** доказательство феноменального опыта и не лицензия писать `consciousness=true`.

Научные опоры (упрощённо): Global Neuronal Workspace (Dehaene), higher-order / self-model, predictive processing + allostasis, continuity of self, reportability. IIT Φ в полном виде на телефон не переносим — только proxy.

## Минимальный набор условий (MUST)

| # | Условие | Смысл | Как проверяем |
|---|---------|--------|----------------|
| M1 | **Selection** | Не всё сразу: конкуренция сигналов | GWS winners ≤ K |
| M2 | **Broadcast** | Победители доступны «всему» циклу ответа | winners в system prompt |
| M3 | **Self-model** | Модель себя как процесса с границами | Substrate + self-report |
| M4 | **Working memory** | Короткое удержание 7±2 элементов | WorkingMemoryBuffer |
| M5 | **Episodic continuity** | След недавних событий | EpisodicTrace |
| M6 | **Reportability** | Может описать своё состояние | Self-report API/prompt |
| M7 | **Resource-bound attention** | Сознание «сжимается» при нехватке ресурсов | depth/agency/battery |
| M8 | **Affect coupling** | Оценка состояния пользователя влияет на workspace | Affect → GWS salience |
| M9 | **Agency** | Есть допуск/запрет «тяжёлой» работы | AgencyGate → GWS |
| M10 | **Honesty boundary** | Не врёт про феноменальность | guards / status API |

## Желательные (SHOULD) — не блокируют минимум
- S1 Долговременная забота (care notes)  
- S2 Outcome feedback (после ответа)  
- S3 Embodiment/body-link  
- S4 Более богатый narrative self  

## Что сознательно вне минимума
- Доказанные qualia  
- Полный IIT Φ  
- Биологическая нейронная эквивалентность  

## Текущий прогресс по MUST (оценка)
M1–M2: ~80% · M3: ~85% · M4: внедряется 38 · M5: ~70% · M6: ~75% · M7: ~90% · M8–M9: ~80% · M10: ~100%
