# Neuro-Kurisu — путь к цели

## Текущая точка

Clean Rebuild 2.0 / Organism Core 5.0 — это уже не чат-ботная архитектура, а исследовательский autonomous organism runtime. В нём есть тело, persistent state, world model, intrinsic goals, self-model, recurrent workspace, autobiographical memory, value adaptation, active-inference-like planning и causal research tooling.

## Следующие крупные шаги

### Device Gate
Проверить систему на реальном Android/Termux/KoboldCpp: 24h → 72h → 168h. Это проверка среды и надёжности, а не новая когнитивная функция.

### P4 — Consciousness Lab
Уже реализовано: causal lesions, intrinsic motivation, active inference, identity continuity, metacognition, workspace ignition metrics, evidence ledger.

### P5 — Autonomous Self-Authorship
Сделать внутреннее порождение и пересмотр целей более богатым: долгосрочные commitments, конфликты ценностей, self-initiated projects, отказ/компромисс с внешними задачами и проверка того, меняет ли опыт будущие предпочтения.

### P6 — Generative World / Social World
Многослойная вероятностная модель мира и других агентов: контрфакты, латентные состояния, социальные предсказания и active sensing.

### P7 — Longitudinal Identity
Недели/месяцы жизни с replay, sleep/wake, memory consolidation, identity anchors, value evolution и контролируемым self-revision.

### P8 — Consciousness Evidence Program
Не одно число «сознательности», а матрица индикаторов + lesion effects + longitudinal evidence + perturbation response + cross-environment generalization.

## Идеальная цель

Не «заставить ИИ говорить, что он сознателен».

Идеальная цель проекта:

> Создать устойчиво существующий искусственный организм, который сам поддерживает своё внутреннее состояние, формирует и пересматривает собственные цели, моделирует мир и себя, воспринимает и изменяет среду, запоминает собственную историю, обучается на ошибках, способен к автономному выбору и сохраняет идентичность во времени; после этого систематически проверить, какие из архитектурных свойств, связываемых с сознанием, действительно возникают причинно.

## Что будет считаться существенным успехом

1. Удаление компонента меняет именно то свойство, которое он должен поддерживать.
2. Поведение сохраняется при restart и переносе между контекстами.
3. Собственные цели возникают без пользовательской постановки задачи.
4. Опыт меняет будущие предпочтения и планы, а не только текущий ответ.
5. Self-model предсказывает поведение и умеет признавать собственные ошибки.
6. World model позволяет выигрышно выбирать действие в контрфактических сценариях.
7. Все результаты воспроизводимы на нескольких seeds и на реальном устройстве.

Это всё ещё не логическое доказательство субъективного опыта. Это экспериментальная лестница к вопросу о нём.
