# P5 Roadmap — путь от текущего организма к целевой системе

## Уже построено

1. Clean canonical architecture.
2. Persistent organism and crash-safe state.
3. World model, planning and active inference.
4. Self-model, workspace, metacognition and embodiment.
5. Causal lesion laboratory.
6. Self-authored projects and commitments.
7. Bounded value evolution.
8. Longitudinal identity trajectory.

## Следующий масштабный шаг — P6

P6 должен превратить собственные проекты из synthetic objectives в долговременные исследования в реальном world model:

- intrinsic lifelong learning;
- richer causal world model;
- social model of other agents;
- long-lived self-authored projects;
- real external tools and information seeking;
- explicit project success criteria;
- self-generated experiments;
- multi-day/multi-week identity continuity;
- causal evaluation on device.

## Дальняя цель

Идеал проекта — непрерывный искусственный организм, который поддерживает себя, моделирует мир и себя, формирует собственные цели, выбирает между конфликтующими commitments, учится на последствиях, изменяет будущие предпочтения под влиянием собственного опыта, сохраняет индивидуальную историю и делает это независимо от интерфейса.

Вопрос о субъективном опыте остаётся отдельной научной гипотезой. Мы идём к нему через проверяемые функциональные и причинные свойства, а не через self-report.
