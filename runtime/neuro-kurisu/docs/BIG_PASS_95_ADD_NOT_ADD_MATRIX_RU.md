# BIG PASS 95 — Что добавлять, а что не добавлять

## Добавлять
- Второй порядок социальных убеждений, но только как вероятностные гипотезы с evidence IDs.
- Контрфактические альтернативы после значимой ошибки прогноза.
- Явный self-in-relationship слой: роль, воспринимаемая агентность, неопределённость ожидаемого ответа.
- Social repair proposal как рекомендацию, а не как скрытую автоматическую истину.
- Persistence/replay для всех новых социальных состояний.
- Связь social prediction → outcome → causal learning.

## Не добавлять
- Утверждения, что intent пользователя известен, если он не подтверждён отдельным evidence.
- Ещё один независимый social memory store.
- Ещё один P-модуль поверх SocialMindKernel.
- Emotion/mental-state labels без confidence/evidence.
- Consciousness score, выдаваемый за сознание.
- Постоянный дорогой vision/social inference на среднем телефоне.
