# N.E.K.O. ASR provider boundary for NK1

Status: provider contract and runtime seam implemented; no N.E.K.O. ASR sidecar, VAD model, Smart Turn model, audio transport or production provider is started by this change.

## Ownership

NK1 remains the single owner of cognitive turns, memory, identity and external action policy. A host may inject one ASR provider through `RuntimeConfig.nekoAsrProvider`; `EmbodimentRuntime.listenDetailed()` returns the transcript together with provider ID, ASR confidence, language, event ID and turn ID; `OrganismRuntime.listen()` and `voiceTurn()` carry these values into the existing multimodal speech evidence. Confidence is preserved as supplied (including `0`); only providers that do not expose confidence use the legacy `0.86` fallback. The transcript-only `listen(): Promise<string | null>` API remains backward-compatible. When no provider is supplied, the existing Termux `termux-speech-to-text` path remains unchanged.

## Provider contract

The host implements `NekoAsrProviderPort`:

- `providerId` identifies the selected provider.
- `isAvailable()` reports current provider availability.
- `captureFinal({ sessionId, signal })` resolves with one versioned `neko.asr.transcript` envelope, or null.
- Optional `cancelSession({ sessionId, reason })` returns `requested` and `verified`. The adapter reports a verified interruption only when both are exactly true.

The host owns process startup, audio capture, provider credentials, microphone permissions, VAD, endpointing and transport. The adapter does not execute shell commands or create a sidecar.

## Admission boundary

The adapter accepts only plain data objects with the exact v1 envelope fields, a current host-generated session ID, the configured provider ID, `phase: final`, and `speakerRole: user`. Partial hypotheses and assistant output are rejected. Accessors, proxies, exotic prototypes, unknown keys, invalid confidence/language, empty text and oversized transcripts are rejected before the transcript reaches NK1. The default transcript limit is 4,000 characters / 16 KiB.

Event IDs are deduplicated in a bounded process-local cache. Reusing an event ID with a different provider/turn/transcript digest is rejected as a conflict. Session IDs are generated by NK1 and must be echoed by the provider; provider-supplied session IDs never create authority.

## Interruption and failure

The adapter passes an AbortSignal to the provider and requests provider cancellation through the optional host port. A request or process exit alone is not considered proof that microphone capture stopped. Unverified cancellation remains an explicit failure state; late transcript results are fenced from the active turn. Provider exceptions are converted to bounded errors and do not bypass the normal cognitive runtime.

## Not included yet

This is a boundary and wiring pass, not a claim of complete voice integration. It does not yet connect N.E.K.O.'s Silero VAD, Smart Turn / endpointing, transcript aggregation, speaker identity, streaming partials, ONNX assets, or any external ASR engine. Those are separate provider/runtime tasks and must be integrated behind this contract with their own holdout, latency, cancellation and mobile soak evidence.
