# BIG PASS 99 — Что добавлять / что не добавлять

## Добавлять

- bounded executable skill policies;
- explicit preconditions/postconditions;
- independent verification;
- fallback branches;
- causal failure records;
- safe adaptation;
- resource-aware execution;
- reusable local routines.

## Не добавлять сейчас

- ещё один planner;
- отдельную SkillMemory2;
- новые P-модули только ради номера;
- автоматическое повышение навыка по собственным self-reports;
- необозначенные fallback side effects;
- утверждения о сознании на основании skill scores.
