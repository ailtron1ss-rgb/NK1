# BIG PASS 111 — ADD / NOT-ADD

| Решение | Статус | Причина |
|---|---|---|
| D-VOI self-directed selection | ADD | организм сам выбирает, куда направить ресурс |
| Opportunity-cost / feasibility | ADD | выбор учитывает цену альтернатив |
| Repetition penalty | ADD | снижает зацикливание на одном дефиците |
| Development campaign plan | ADD | снижает ручную подготовку реального эксперимента |
| Holdout-verified duplicate guard | ADD | не создаёт параллельные конкурирующие hypotheses |
| Synthetic self-reward | NOT-ADD | запрещено принципом проекта |
| Automatic personality/value rewrite | NOT-ADD | слишком высокий риск ложной адаптации |
| Second planner | NOT-ADD | не нужен и создаёт конкурирующую власть |
