# Neuro-Kurisu 35.6.54 — B2512–B2514

## Цель релиза

Перевести результат B2511 Active Epistemic в долговременное обучение организма: добытая информация должна сохраняться как проверяемый эпизод, консолидироваться в семантическое знание без уничтожения исходного доказательства, использоваться для проектирования будущего self-состояния и получать приоритет памяти по потребности.

## B2512 — Epistemic → Semantic Autobiographical Consolidation

Новый слой хранит bounded raw episodes, provenance, confidence, support и contradiction. Консолидация выполняется только по gated evidence; исходные эпизоды не заменяются семантическим summary. Отдельный identity firewall не изменяет B284 identity revision/identity latent напрямую.

### Эксперимент

На noisy hidden-rule holdout gated-семантическая ошибка составила 0.0660 против 0.4380 у непрерывного naive update: относительное улучшение 84.93%. Raw retention = 192, identity firewall = 1.0, protected identity drift = 0.

## B2513 — Future Self Projection Field

Action-conditioned projection связывает текущий identity latent, semantic memory, self/world latent и goal vector. Выполняются bounded multi-action rollouts, затем verified outcome обновляет action-specific projected utility.

На learning holdout: 700 циклов, 14 700 rollouts, 700 learning updates; verify utility превысила explore на 0.04976; future coherence = 0.99981; prediction error = 0.21080.

## B2514 — Memory Need Prioritizer

Память получает bounded need score из surprise, novelty, goal relevance, identity relevance, prediction error и verification. В runtime ключи bucketed, чтобы не создавать новый элемент на каждый tick.

Direct test корректно поднял surprise-event на первое место; runtime item count после 12 циклов = 7.

## Принцип безопасности архитектуры

B2512 semantic consolidation не имеет права непосредственно переписывать identity. B2513 получает identity как вход и выдаёт bounded action bias, а не вторую executive policy. B2514 только ранжирует memory need.
