# BIG PASS 97 — ADD / DO NOT ADD

## ADD

- evidence-aware reusable skills;
- bounded context transfer;
- validated success history;
- skill provenance;
- conservative promotion/demotion;
- low-cost policy reuse on the phone;
- future compound routines only after repeated verified tool sequences.

## DO NOT ADD

- second independent skill database;
- skill promotion from self-generated success only;
- automatic tool execution bypassing ActionGateway;
- unrestricted generalisation from semantically unrelated contexts;
- claims that a promoted skill proves intelligence or consciousness.
