# BIG PASS 104 — Что добавлено / что не добавлено

| Область | Решение | Причина |
|---|---|---|
| Replay retention | Добавлено | Нужна измеримая проверка, а не только reactivation |
| Delay-aware curve | Добавлено | Позволяет строить первые retention diagnostics |
| Independent evidence gate | Добавлено | Не смешивать внутреннюю гипотезу с подтверждённым результатом |
| Pair matching | Добавлено | Исправляет методологическую ошибку Pass 103 |
| Memory↔skill binding | Добавлено | Связывает обучение и procedural ecology без нового memory store |
| Cluster replay counters | Исправлено | Удаляет декоративное состояние |
| Replay→causal→unified validation route | Добавлено | Усиливает синергию уже существующих систем |
| Новая память | Не добавлено | Дублирование MemoryOS2 было бы хуже |
| Второй planner | Не добавлено | Конфликт ownership/контуров |
| Runtime self-codegen | Не добавлено | Не требуется для цели pass |
| Consciousness claim | Не добавлено | Нет экспериментального основания |
| Full biological consolidation claim | Не добавлено | Искусственная архитектура не является доказательством биологического механизма |
