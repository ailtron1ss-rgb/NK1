# WorkPass573 — стабилизация контекста извлечения памяти

**Дата:** 2026-10-27
**Ветка:** `workpass70-source`
**Категория:** память / когнитивная маршрутизация.

## Диагноз

В `MemoryOS2.retrieve()` сигналы `contextTemporal` и `contextCausal` частично получались из накопительных счётчиков `semanticQueries` и `linkUpdates`. Поэтому история использования могла менять интерпретацию нового запроса: после большого числа общих обращений вопрос без временных маркеров превращался в «временной», а накопленные изменения графа могли искусственно поднимать «причинный» контекст.

Это смешивало телеметрию всей жизни системы с намерением текущего запроса и могло переключать `AdaptiveMemoryPolicy` на неправильный контекст. Исправление оставляет эти счётчики статистикой, но не использует их как замену смысловым признакам.

## Изменение

- Контекст маршрутизации теперь выводится из текущего интента, маркеров причинности/времени и явно заданного временного режима.
- Добавлена регрессия на 80 общих запросах подряд, затем на временном и причинном запросах; она проверяет отдельные контекстные ключи.
- Проверка зарегистрирована в `test:rebuild-recovered`, но не запускалась в этом проходе.
- Не добавлялась внешняя зависимость: исправление локально для канонического MemoryOS2.

## Основание и дальнейшие этапы

Подход согласуется с разделением indexing/retrieval/reading в [LongMemEval (ICLR 2025)](https://proceedings.iclr.cc/paper_files/paper/2025/hash/d813d324dbf0598bbdc9c8e79740ed01-Abstract-Conference.html): retrieval должен измеряться как отдельная стадия, а временной контекст — опираться на фактические запросы/события, а не на общий объём трафика. Для следующего прохода использовать независимые разметку и holdout; учитывать устаревшие сведения и корректную абстенцию по [Memora/FAMA (ACL 2026)](https://aclanthology.org/2026.findings-acl.1337/). Это направление для интеграции в оценивание, а не заявление о положительном uplift.

## Границы утверждений

Код, регрессия, npm script и CHANGELOG записаны в `workpass70-source`. Тесты не запускались, независимый recall uplift не установлен, Release ZIP не обновлялся. Исправление устраняет найденный источник дрейфа контекста, но не доказывает субъективное сознание или готовность всего NK1 к production.
