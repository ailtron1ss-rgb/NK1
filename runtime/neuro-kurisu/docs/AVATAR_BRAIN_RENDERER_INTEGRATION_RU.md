# NK1 — интеграция мозга и рендереров аватара (2026-11-02)

## Единый источник состояния
Канонический `OrganismSnapshot` один раз адаптируется через `projectOrganismSnapshotToAvatarBrain` в существующую чистую функцию `projectAvatarBrainState`. Отдельная модель личности или параллельный оценщик эмоций не создаются.

## Подключённые каналы
- **Live2D:** текущий строгий `EmbodimentIntentV1` получает интенсивность выражения из когнитивной проекции, смешанный взгляд и ограниченный наклон головы. Сохраняются существующие часы речи, отмена, дедупликация motion и ACK.
- **Original SVG 2D:** взгляд берётся из той же проекции; семантические выражения остаются на существующей карте эмоций.
- **VRM/3D:** взгляд и выраженность эмоции передаются в существующие нормализованные VRM humanoid/expression адаптеры. В reduced-motion ограничивается процедурная анимация головы/корпуса и отключается случайное моргание.
- **Память → аватар:** только максимальная salience воспоминаний, присутствующих в текущем `lastDecision.retrievedIds`, сводится к `memoryRecall01`. ID, текст, дневник, чат и мысли не попадают в проекцию.
- **Личность:** источником остаются именованные черты текущего снимка; тепло, любознательность, самообладание, игривость и прямота используются имеющейся когнитивной проекцией/моторикой.
- **Сон:** напрямую передаётся `snapshot.awake`; тепловые, батарейные и другие отсутствующие физические датчики не выдумываются.

## Честные границы моделей
- **Live2D:** существующий Cubism asset/render path подключён; необходимы реальные browser/mobile visual и timing soak.
- **3D:** интеграция выполняется на уровне процедурной сцены и VRM/GLB адаптера. Наличие законченной одобренной лицензированной Kurisu VRM-модели и E2E на устройстве эта работа не доказывает.
- **2.5D:** общая проекция выдаёт layered hints, но production renderer не объявляется готовым и не добавляется как selectable mode. Нужны отдельные слои персонажа, дорисованные скрытые области, pivots, masks, depth order и визуальная приёмка.

## Проверки
Добавлены сценарии общей проекции для 2D/2.5D/3D, свежести сигнала, salience извлечённой памяти, отсутствия текста/ID в renderer-данных и подавления движения при сне/низкой энергии; добавлена проверка границ интенсивности VRM-выражения.
Результаты GitHub Actions, реальный браузер/мобильный рендер, lip-sync drift и soak учитываются отдельно. Изменение не обновляет стабильную ветку или Release ZIP.
