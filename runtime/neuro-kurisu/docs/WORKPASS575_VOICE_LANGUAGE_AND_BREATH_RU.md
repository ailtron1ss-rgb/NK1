# WorkPass575 — язык и режим речи

**Дата:** 2026-10-27  
**Ветка:** `workpass70-source`  
**Категория:** голос / личность / воплощение.

## Найденный разрыв

Серверный `VoiceEmbodiment.buildVoicePlan()` создавал просодию с фиксированным `language: 'ru-RU'`. Между тем браузерный `AvatarStage` уже выбирает локаль по доминирующему алфавиту ответа. В итоге один и тот же англоязычный ответ мог маршрутизироваться по разным языковым предположениям в browser и backend TTS.

Параллельно серверная функция `detectVoiceBreathMode()` понимала русские маркеры приветствия, объяснения, самоописания и спора, но почти не распознавала их английские аналоги.

## Изменение

- Добавлен `inferVoiceLanguage()`: английский выбирается, если латинских букв больше, чем кириллических; смешанный текст с преобладанием кириллицы остаётся русским. Для текста без букв сохранён безопасный русский default.
- Добавлены английские маркеры для режимов ping/confess/lecture/argue; русские маркеры сохранены.
- `buildVoicePlan()` теперь использует вывод языка из текста.

## Ограничения

Это эвристика для русского и английского, не полноценное определение языка для многоязычных или транслитерированных текстов. Проверки и реальное воспроизведение через Android/Termux не запускались. Следующий этап — использовать явный язык ответа из языкового backend, когда он предоставляется, и свести его с browser TTS и аудиочасами Live2D без расхождения событий.
