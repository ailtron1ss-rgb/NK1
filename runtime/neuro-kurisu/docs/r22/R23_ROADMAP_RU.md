# R23 Roadmap — Deep Semantic Coverage / Memory Regret / Mobile Reality

1. Raise critical operation evidence from 45 runtime records to a deliberately selected 100–200 operation frontier across world, learning, agency and perception.
2. Add eviction-regret witness: when value-ranked forgetting is later needed, record regret and feed it back into the retention policy.
3. Add LongMemEval-V2-inspired internal experience battery: static state, dynamic state, workflow, environment gotchas, premise awareness.
4. Extend actionable world-model evaluation to multi-step action sequences and counterfactual regret, not only one-step action choice.
5. Run 1000+ cycle Android/Termux endurance on the real target device.
6. Prototype a bounded recurrent/SSM substrate as a separate experimental lane; integrate only after ablation proves it adds measurable value.
