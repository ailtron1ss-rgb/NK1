# B293 — Function Reality Closure cohort

B293 does not auto-promote functions into the global VERIFIED bucket. Instead it establishes a reusable behavioral passport cohort for the new neural component.

## Directly exercised public API
- restore — persistence schema normalization and restoration.
- snapshot — serializable state round-trip.
- step — recurrent neural update and bounded output.
- learnFromOutcome — outcome-conditioned plasticity.
- actionBias — action-conditioned predictive bias.
- metrics — scalar operational telemetry.
- diagnostics — bounded detailed telemetry.
- lesion — causal ablation state.
- clearLesion — restoration from lesion.

## Evidence criteria
A method is considered locally evidenced only when the test observes a non-error execution, finite outputs, bounded state, persistence or causal effect where applicable, and at least one behavioral assertion beyond mere function invocation.

Global semantic VERIFIED status is intentionally unchanged. This document is an evidence passport for the cohort, not a metadata promotion.
