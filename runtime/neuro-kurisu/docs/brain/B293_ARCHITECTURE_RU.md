# B293 Architecture — Self/World Predictive Microcircuit

B293 is not a new personality owner. It is a bounded predictive neural substrate situated beneath B290/B291/B292.

Observation -> B293 recurrent microcircuit -> self/world near-term prediction -> B290 developmental pressure + B291 executive evidence -> action -> real outcome -> B293 plasticity + B291/B292 learning.

The circuit contains 24 neurons, leaky membrane state, thresholds, refractory periods, pre/post eligibility traces, recurrent weights, action-specific bias, prediction error and a bounded 128-record history. Its learning rule combines reward/prediction-error teaching with a small Hebbian/STDP-like term and weight damping/homeostasis.

The system is deliberately smaller than B269 and specialized rather than redundant: B269 is a broader spiking substrate; B293 is a consequence-predicting microcircuit for self/world coherence. It should remain subordinate to the shared state/agency layers.

Mobile policy: neural update every 4 organism ticks, checkpoint every 64 ticks. Balanced policy: update every 8 ticks, checkpoint every 16 ticks. Quality policy: update every 2 ticks, checkpoint every 8 ticks.

The design is intended as a research mechanism, not a claim of biological equivalence or consciousness.
