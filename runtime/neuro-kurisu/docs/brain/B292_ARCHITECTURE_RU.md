# B292 Architecture

## Fast timescale
Sensorium -> world/self state -> candidate actions -> B291 executive gate -> constitutional/action finalization.

## Medium timescale
B292 Cognitive State Bus normalizes identity, agency, goal pressure, novelty, uncertainty, energy, thermal state, prediction error and executive/developmental gates once per cycle.

## Slow timescale
B290 developmental reality gate adjusts exploration/verification/consolidation/reflect/recovery/protect policy. B292 Intent Trace records continuity of working intentions and outcome adaptation.

## Ownership rule
B289 integrates neural substrates. B290 coordinates developmental plasticity. B291 selects/guards current intention. B292 records cross-cycle intention continuity and provides a shared state view. None of B289-B292 claims ownership of phenomenal consciousness.
