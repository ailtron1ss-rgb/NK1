# Правила архитектуры искусственного мозга — BIG PASS 207

1. Ни одна новая brain-system не создаётся без записи в `ArtificialBrainAtlas`.
2. Новая система должна иметь одного computational owner; фасады и адаптеры не считаются владельцами.
3. Biological analogy и verified computational behaviour — разные уровни доказательства.
4. Любой cross-system causal claim требует отдельного ablation/replay evidence.
5. Анатомическая полнота не является целью сама по себе: добавляется только та детализация, которая создаёт новое проверяемое вычислительное свойство.
6. На среднем телефоне expensive brain subsystems должны иметь explicit cadence/energy/thermal budget.
7. Human-like consciousness не считается следствием анатомического сходства; это отдельная adversarial research question.
8. Existing modules переиспользуются и объединяются вместо создания параллельных P/Pxx дубликатов.
