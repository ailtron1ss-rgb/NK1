# BRAIN PASS 212

B212 adds a computational cortical microcircuit layer on top of B211.

The pass is considered real progress only because the new layer:

- causally changes candidate gains;
- performs sparse competition;
- increases recurrent braking under unstable/high-surprise conditions;
- participates in Core integration;
- survives persistence/restart;
- passes independent regression and release gates.

This pass intentionally does **not** claim biological equivalence.
