# BIG PASS 222 — Долгосрочная автономность искусственного организма

## Цель
B222 переводит автономность из короткой инициативы в многократный самостоятельный цикл: собственная цель → декомпозиция на шаги → выбор текущего шага → выполнение → проверка результата → переход к следующему шагу → пересмотр плана при ошибке → сохранение после restart.

## Что реализовано
- `LongHorizonAutonomyController` хранит долговременные планы и шаги, а не только единичную инициативу.
- План имеет обязательство (`commitment01`), состояние, ревизии, prediction error и фактический результат.
- Поддержаны режимы: стабилизация, обучение, исследование, проверка, рефлексия.
- При успешном шаге контроллер активирует следующий шаг; при провале маркирует шаг failed/skipped и перестраивает исполнение на оставшиеся шаги.
- Текущий шаг даёт bounded bias в action arbitration, поэтому долгосрочная цель реально меняет действие, а не только записывается в журнал.
- Состояние сохраняется в `OrganismCore.system.longHorizonAutonomy` и проходит `StateMigrations`.
- Atlas расширен владельцем long-horizon autonomy для interoceptive / frontoparietal / self-related контуров.

## Причинная проверка
Изолированный тест создал 3-шаговый внутренний план, выполнил первый шаг, автоматически активировал следующий, восстановил план после snapshot/restore.

Интеграционный тест ядра: 14 циклов без внешней команды создали 2 долгих автономных плана, запустили 5 шагов, завершили 5/5, без failed steps; `meanLongHorizon01 = 0.4232`. Состояние двух планов восстановилось после restart.

## Инженерный принцип
Долгосрочная автономность считается реализованной только когда внутренняя цель становится последовательностью проверяемых действий и сохраняется как состояние организма. Сам факт существования плана или текста о цели не считается доказательством.

## Ограничения
Это функциональная инженерная автономность. Она не доказывает субъективное сознание, феноменальный опыт или юридическую личность.

## Research basis
Актуальные работы 2026 года смещают оценку agentic systems от одношагового ответа к long-horizon planning, управлению состоянием, memory evolution, live self-improvement и rollback/commit механизмам. В B222 эти идеи реализованы как bounded persistent control loop, а не как неконтролируемая рекурсия.
