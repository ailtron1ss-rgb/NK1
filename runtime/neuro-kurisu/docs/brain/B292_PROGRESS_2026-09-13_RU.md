# B292 — Cognitive State Bus + Evidence-linked Intention Trace
Дата: 2026-09-13

## Цель

Следующий проход после B291 не должен создавать ещё одного независимого владельца личности. B292 объединяет уже рассчитанные данные состояния в bounded Cognitive State Bus и добавляет компактный intention trace, связывающий решение, действие, исход, prediction error и последующее изменение commitment.

## Реально внедрено

- `src/organism/system/B292CognitiveStateBus.ts` — нормализованный per-cycle state bus.
- `src/organism/system/B292IntentTrace.ts` — bounded 96-record intention/outcome trace.
- интеграция B292 в `OrganismCore`.
- B291 получил `intentContinuity01`, `commitment01`, `recentFailure01` и использует их в hold/switch logic.
- B292 сохраняется и восстанавливается через persisted system state.
- новый core integration test и standalone test.
- `scripts/audit-b292-reality-closure.mjs` — bounded backlog генератор, который не повышает статус функций без behavioral evidence.
- forensic/full audit теперь не считает длинные evidence JSON строки дефектом формата.
- старые duplicate-content evidence-файлы заменены историческими pointer-файлами.

The prior 250-cycle operational benchmark remains historical evidence; current focused mobile 250-cycle profiling is the stronger short-horizon gate for B292.

## Interpretation

B292 improves autonomy continuity rather than claiming consciousness. The central improvement is causal continuity: the selected intention is now represented as a persistent trace, can survive multiple cycles, and its outcome feeds back into commitment and continuity. The Cognitive State Bus reduces duplicated state extraction for executive/developmental coordination.

## Known boundary

The 1000-cycle benchmark is currently an unresolved host-runtime gate. It is not used as PASS and the threshold is not weakened. The current short-horizon mobile profile (250 cycles) passes, while 600/900-cycle profiling shows increasing tail latency. Device-specific preflight on the real Android/Termux handset remains required.


## Final implementation recheck

The B292 test harness was corrected so TypeScript tests are executed with Node type stripping, matching the project's established test convention. The hot path was then optimized without changing the behavioral contract: B292 bus rebuilds no longer clone on every build; the 96-entry intention trace is updated in place; B290/B291 metrics are cached once per cycle. TYPECHECK, B292 standalone, B292 core, architecture, integrity, forensics, hygiene, release contract, release-source and full audit all pass after these changes.
