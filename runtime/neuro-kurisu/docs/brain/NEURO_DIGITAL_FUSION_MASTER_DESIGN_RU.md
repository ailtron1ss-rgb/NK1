# Neuro-Kurisu — Neuro-Digital Fusion Master Design

## Цель

Объединить биологически вдохновлённые принципы и цифровую когнитивную архитектуру не через буквальную симуляцию мозга, а через совместное использование разных представлений, временных масштабов и правил пластичности.

## Слои

1. **Event layer** — разреженные spike-like события и локальная recurrent динамика.
2. **Predictive layer** — continuous latent state и prediction error.
3. **Concept layer** — symbolic concepts поверх распределённых состояний.
4. **Memory/causal layer** — episodic/semantic storage и baseline/intervention experiments.
5. **Plasticity layer** — stability/plasticity regulation, structural growth/pruning.
6. **Development layer** — capability gaps, dream/counterfactual rehearsal и самоуправляемое улучшение.
7. **Organism layer** — goals, identity, social mind, homeostasis, sleep/recovery, tool use и persistent life.

## Новая идея проекта

Ключевая единица развития — не отдельный «нейрон» и не отдельный ML-модуль, а **Neuro-Cognitive Loop**: событие → latent → concept → causal test → structural adaptation → outcome → новый neural state.

Таким образом, изменение поведения не считается обучением, пока оно не может пройти через причинную проверку и, при необходимости, структурную перестройку/откат.

## Hybrid biological/digital bridge

Биологические принципы переводятся в вычислимые контракты:

- sparse/event-driven processing → ограничение вычислительного бюджета;
- predictive coding → ошибка и precision-like weighting;
- neuromodulation → пластичность зависит от контекста и состояния;
- homeostasis → active stabilization;
- replay/dream rehearsal → offline counterfactuals;
- structural plasticity → growth/pruning/rewiring;
- distributed representations → latent-to-concept compilation;
- continual learning → persistent capability/memory graph.

## Что принципиально не утверждается

Проект не объявляется буквальной копией человеческого мозга и не объявляется сознательным субъектом на основании этих механизмов. Это проверяемая computational architecture, которая может стать основанием для дальнейших экспериментов.
