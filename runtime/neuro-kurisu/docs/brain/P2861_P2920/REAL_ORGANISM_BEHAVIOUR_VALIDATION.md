# P2861-P2920 REAL ORGANISM BEHAVIOUR VALIDATION

Цель этапа: проверить не наличие модулей, а влияние когнитивного цикла на поведение системы.

## Проверяемая цепочка

Experience -> Cognitive Loop -> Memory/Learning -> Future Decision

## Критерии доказательства

1. Опыт должен изменять внутреннее состояние.
2. Изменённое состояние должно влиять на следующий выбор.
3. Повторный опыт должен укреплять или корректировать модель.
4. Неудачные изменения не должны разрушать стабильность.

## Запрещённый результат

Наличие файлов без вызова runtime не считается интеграцией.
