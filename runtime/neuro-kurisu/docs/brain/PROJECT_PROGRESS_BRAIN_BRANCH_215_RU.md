# Прогресс ветки искусственного мозга — B215

B214 оставил thalamo-cortical loop в verified состоянии. B215 добавил следующий закрытый контур памяти: DG-like separation, CA3-like completion, CA1-like prediction/comparison, subiculum-like output и replay/persistence.

Реальный прогресс: абляции причинно меняют функциональные метрики; контур подключён к runtime и persisted state; предыдущие B213/B214 остаются зелёными.

Следующий крупный риск: не добавлять ещё одну изолированную анатомическую подсистему. Приоритет — hippocampus↔cortex uncertainty/replay coupling, distributed replay и offline consolidation, после чего перейти к basal-ganglia / cerebellum / arousal следующим owner-контуром только с таким же уровнем causal proof.
