# Termux — как пользоваться организмом без ручного задания времени

## Повседневный сценарий

1. Один раз установить проект по `docs/TERMUX_ZERO_TO_RUN_POCO_RU.md`.
2. Запустить:

```bash
cd "$HOME/Neuro-Kurisu/app"
bash scripts/termux/start.sh
```

3. Общаться через `http://127.0.0.1:3000`.
4. Завершить Termux/процесс когда угодно.
5. В следующий раз снова выполнить запуск.

Организм не просит вводить дату/время. При старте он сам берёт системные часы телефона, видит последний checkpoint и рассчитывает промежуток отсутствия.

## Что он запоминает

- когда началась текущая сессия;
- когда закончилась предыдущая сессия, если завершение было корректным;
- когда был последний checkpoint;
- сколько времени организм провёл активным;
- сколько времени провёл между запусками;
- сколько было запусков и прерываний;
- текущую дату, время, часовой пояс и день недели.

## Если Termux убили без shutdown

Это тоже поддержано. Незакрытая сессия остаётся в состоянии. При следующем старте новая сессия видит gap и отмечает его как interruption, но состояние личности/памяти не сбрасывается.

## Очень длинное отсутствие

100000 часов и больше не превращаются в 100000 часов вычислительной нагрузки. Система хранит gap как число миллисекунд и классифицирует его. Это принципиально важно для экономии батареи и сохранения целостности.
