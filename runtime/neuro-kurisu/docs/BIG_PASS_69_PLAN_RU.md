# BIG PASS 69 — PLAN

Цель: превратить P84 из пассивного lineage-слоя в доказательно ограниченный механизм causal carry-over между подтверждённым прошлым и будущим выбором.

## Принцип
Не создавать новый physical subsystem и не дублировать Memory/EventLog/Reality. P84 хранит только компактные профили исходов действий и использует их как bounded bias.

## План
1. Добавить bounded profiles подтверждённых исходов действий.
2. Учить profile только от достаточно сильного external verification / corroboration.
3. Ввести decay и жёсткий ±0.06 bias ceiling.
4. Подключить bias до constitutional arbitration, чтобы эффект участвовал в выборе.
5. Сохранить/восстановить профили через migration и restart.
6. Добавить API для аудита carry-over.
7. Проверить, что слабые или неизвестные данные не меняют поведение.
8. Сравнить hot-path и long-horizon стоимость.
9. Пересмотреть предыдущие BIG PASS 64–68 и исправить drift только в audit/source-of-truth.
