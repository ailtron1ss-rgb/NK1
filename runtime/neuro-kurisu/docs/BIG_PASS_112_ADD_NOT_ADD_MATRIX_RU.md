# BIG PASS 112 — ADD / NOT-ADD

| Решение | Статус | Причина |
|---|---|---|
| Learning investment decision | ADD | обучение становится ресурсным самостоятельным выбором |
| Opportunity cost gate | ADD | обучение не должно безусловно расходовать ресурс |
| Recover mode | ADD | организм может отказаться от learning при истощении |
| Persisted decision ledger | ADD | выбор становится наблюдаемой частью развития |
| Core integration before proposal | ADD | решение реально влияет на runtime path |
| Synthetic reward from investment decision | NOT-ADD | создаёт circular learning |
| Automatic value/personality rewrite | NOT-ADD | недостаточно evidence и слишком высокий риск |
| Second planner | NOT-ADD | дублирование полномочий |
