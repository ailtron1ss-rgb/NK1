# Experience Continuum Architecture

Canonical source of memory truth: `MemoryOS2`.

Derived layer:
`MemoryOS2 -> ExperienceContinuumFabric -> summary/graph/tiering -> P70/P75 hints -> UI diagnostics`

No reverse write from Experience Continuum into canonical memory or identity is performed automatically.

## Tiers
- HOT: recent/retrieved/identity-critical high-significance experience.
- WARM: active contextual experience with moderate future/goal relevance.
- COLD: older low-pressure experience eligible for bounded clustering.

## Identity Gravity
`experience -> identity pressure -> resistance -> tension -> proposed change`

The proposal is not an identity mutation.
Evidence support is tracked separately to avoid conflating salience with truth.

## Compression
Cold compression creates compact derived clusters. Canonical memory remains intact.

## Integrity
Potentially dangerous cases are flagged:
- unknown source;
- identity-critical low confidence;
- high identity hypothesis risk;
- quarantined source status.

The system does not silently upgrade uncertain material into identity truth.
