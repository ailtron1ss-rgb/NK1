# Developmental Attractor Field Architecture

`DevelopmentalAttractorField` is a derived developmental learning layer. It is not the canonical identity/value owner.

## Purpose
Convert repeated evidence, success/failure, contradiction, values and developmental phase into slow-moving behavioural attractors.

## Current attractors
curiosity, truthfulness, autonomy, care, responsibility, exploration, repair, connection.

## Safety properties
- bounded strength/stability/confidence
- idempotent evidence keys
- bounded action bias
- provenance through `evidenceKey`
- non-consciousness claim

## Closed loop
experience → evidence → attractor adjustment → motive/goal bias → action → consequence → next experience.

## Important limitation
An attractor is not a personality slider and not evidence of consciousness.
