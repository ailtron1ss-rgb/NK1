# BIG PASS 92 — Add / Do not Add / Defer

## ADD NOW

- Explicit semantic-vision backend contract.
- Semantic pending-request lifecycle: acquisition != understanding.
- Resource-aware camera acquisition gate.
- Persistent sensorium metrics.
- Server status/capture-if-useful endpoints.
- Regression tests for metadata, backend path lifecycle, semantic fulfillment and cleanup.

- Another P-module solely to represent vision.
- Fake object detector based on filenames/hashes.
- A consciousness score derived from camera richness.
- Mandatory heavy native ML dependency.
- Continuous camera polling on the phone.
- Automatic semantic claims when no semantic backend exists.

- Scene graph learning from repeated visual episodes.
- Sensor→world→causal→memory coupling using semantic vision outputs.
- Social interpretation of detected persons.
