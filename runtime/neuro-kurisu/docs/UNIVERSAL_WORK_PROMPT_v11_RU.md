## New mandatory developmental evidence rule
Whenever a BIG PASS claims that experience changes future identity/strategy/behavior, require a paired causal divergence experiment:

**same initial state → controlled divergent experience → same future context → compare future decisions**

The experiment should also include:
- counterevidence/reversal pressure;
- persistence/reload verification;
- an ablation or reduced-mechanism comparison when practical;
- explicit resource-cost accounting on the target runtime.

Behavioral divergence is functional evidence, never a consciousness proof.

All v6/v10 rules about canonical ownership, no decorative complexity, legacy protocol, unified sensorium, world model, memory truth, agency, social mind, embodiment, mobile qualification, epistemic firewall and consciousness discipline remain in force.
