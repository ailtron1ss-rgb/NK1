# Дополнительные идеи — накопительный каталог

Этот файл живёт внутри архива и должен читаться следующими версиями перед крупным рефакторингом.

## Уже внедрено в P21

Shadow Organism; Behavioral Gene Bank; Surprise Firewall; Evidence Debt; Model-Swap Olympics (evaluation layer); Offline Survival; Dream Compiler; Time Capsule; Counterfactual Fork Lab.

## Следующий запас идей

1. Shadow organism с отдельным residual world-model, который никогда не исполняет action.
2. Evolutionary policy bank: сохранение не только одной лучшей policy, а нескольких устойчивых «линий поведения».
3. Evidence debt prioritization через expected information gain / risk.
4. Surprise firewall с multi-sensor agreement: одно событие не принимается как истина, пока не получит независимое подтверждение.
5. Offline survival с отложенной batch-синхронизацией после появления сети.
6. Dream compiler → bytecode-like procedural skills с дешёвым запуском.
7. Time capsule diffing: сравнивать две капсулы и строить изменение личности/целей за период.
8. Counterfactual forks с replay одного и того же исторического trace для сравнения политик.
9. Model-swap Olympics: один и тот же набор задач прогонять через local/cloud backends и сохранять paired comparison.
10. Evidence Ledger for self-model: каждое долговременное убеждение о себе должно иметь provenance.
