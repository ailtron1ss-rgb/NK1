# WorkPass578 — исправление шаблонов контекста и языковых маркеров

**Дата:** 2026-10-27  
**Ветка:** `workpass70-source`  
**Область:** память / двуязычный retrieval / голос.

## Исправлено

1. В английских маркерах `detectVoiceBreathMode()` снято двойное экранирование границ слов. Иначе regex мог искать буквальную последовательность `\b` вместо границы слова; приветствия, self-disclosure, объяснение и спор могли не распознаваться.
2. В `MemoryOS2.retrieve()` английские причинные/временные слова оставлены с `\b...` границами, а русские маркеры вынесены в отдельные Unicode-подстроки. Обычный JavaScript `\b` не является полноценной Unicode-границей слова для кириллицы, поэтому общий англо-русский шаблон был ненадёжен.
3. Сохранено разделение телеметрии и намерения текущего запроса: lifetime-счётчики не используются для искусственного включения causal/temporal контекста.

## Граница

Кодовый исправительный проход выполнен на месте. Тесты, TypeScript, серверное воспроизведение и аудио не запускались по выбранному приоритету работы над исходниками. Нельзя утверждать, что весь двуязычный retrieval или TTS уже функционально подтверждён.
