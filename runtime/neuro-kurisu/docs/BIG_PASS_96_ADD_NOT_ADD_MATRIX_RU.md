# BIG PASS 96 — ЧТО ДОБАВЛЯТЬ / ЧТО НЕ ДОБАВЛЯТЬ

## Добавлять

- причинные связи между уже существующими owners;
- developmental consequences с provenance;
- future-self predictions, которые можно сверять с исходом;
- evidence-gated изменения canonical identity/value state;
- bounded representations, пригодные для телефона;
- новые regression-тесты на anti-self-deception правила;
- observability, позволяющую видеть разницу между evidence и inference.

## Не добавлять

- новые P-модули без нового причинного механизма;
- второй parallel memory owner;
- второй policy owner;
- consciousness score без intervention/ablation evidence;
- social intent как ground truth из собственного действия организма;
- тяжёлые native dependencies без доказанного выигрыша на целевом телефоне.
