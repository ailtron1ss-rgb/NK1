# WorkPass568 — двуязычное автобиографическое и сессионное вспоминание

## Изменение

На актуальной канонической source-ветке NK1 расширена классификация запросов памяти на русском и английском языках. Явный вопрос о профиле пользователя проверяется раньше общих фраз о воспоминаниях; запросы о предыдущих разговорах и сессиях получают эпизодическое намерение.

Социальная запись получает повышенное соответствие эпизодическому запросу только тогда, когда её контекст подтверждает устойчивую идентичность беседы (conversation/dialogue/chat/thread/transcript/session ID или key) либо сама запись явно обозначена как история диалога. Идентификаторы отношений, роль собеседника, индекс сообщения и номер хода сами по себе этого не доказывают.

## Каноническая интеграция

- Изменяется только `MemoryOS2`; это не второй memory store и не отдельная recall-ветка.
- Порядок ранжирования остальных типов памяти и канонический владелец `MemoryOS2` сохранены.
- Расширены проверки `memory-query-intent-workpass51.mjs`: profile recall, RU/EN conversation recall, снимок/восстановление и варианты ключей сессии.
- Добавлен детерминированный 30-запросный лексический goldset WorkPass568 и подключены оба теста к `test:rebuild-recovered`.

## Доказательства и ограничения

Goldset построен на синтетических лексических ничьих. Его Recall@1/MRR подтверждают только точность маршрутизации и влияние приоритета типа памяти в контролируемом fixture, а не качество вспоминания на реальной истории диалогов. Независимые пользовательские/сессионные holdout-данные, тесты на реальном runtime и оценка ложных воспоминаний остаются отдельными задачами. Готовность релиза и оценки прогресса не повышаются.
