# BIG PASS 102 — матрица решений

## Добавлено
- Приоритет replay для производной Experience Continuum.
- Явная stability/replayPriority у узлов опыта.
- Ограниченный replay budget, зависящий от cognitive pressure.
- Реактивация узла без изменения канонической MemoryOS2 записи.
- Метрики replay runs/selected/reactivated.
- Публичные Core API для replay candidates/reactivation.

## Не добавлено
- Удаление канонических воспоминаний.
- Генеративная перепись памяти без evidence.
- Неограниченный replay.
- Второй независимый memory store.
- Утверждение, что replay создаёт субъективный опыт.

## Причина
Система получает механизм поддержания доступности значимого опыта, не разрушая каноническую память и не создавая неограниченную вычислительную нагрузку на мобильном устройстве.
