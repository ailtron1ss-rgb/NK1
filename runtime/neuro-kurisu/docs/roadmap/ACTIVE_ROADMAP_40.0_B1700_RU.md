# Active Roadmap — B1700+

## B1701–B1800 — Behavioral Continuity Invariants

Доказывать continuity не по state hash, а по behavior:
- project continuation;
- unfinished intention continuation;
- preference retention;
- autobiographical recall consistency;
- personality-conditioned choice preservation.

## B1801–B1900 — Migration Continuity

- host migration;
- runtime replacement;
- model replacement;
- capability migration;
- rollback without identity reset.

## B1901–B2100 — Longitudinal Identity Stress

- 25k/100k-cycle campaigns;
- controlled forgetting;
- lesion + rehabilitation;
- memory corruption injection;
- repeated restart windows;
- identity drift bounds.

## B2101+ — Persistent Autonomous Personality

Continuity должна стать не только свойством хранения состояния, а causal constraint на развитие личности: прошлые commitments, relationships, values and projects должны ограничивать и направлять будущие решения.
