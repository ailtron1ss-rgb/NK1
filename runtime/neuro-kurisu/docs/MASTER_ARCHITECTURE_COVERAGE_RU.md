### Частично / P23 и следующая реализация
- Learned World Model 2.0: пока hybrid/statistical/causal scaffold, не полноценная neural latent-dynamics learner.
- Procedural skill promotion: P23 добавляет holdout-validated policy skills, полноценное learned policy extraction ещё впереди.
- Social mind: foundation есть, полноценная многоперсонная социальная среда ещё впереди.
- Sensor hierarchy L2-L5: microphone/camera/context event pipeline требует device-side validation и дальнейшего perception work.
- LLM inside workspace: language organ connected downstream; полноценный bidirectional hypothesis/reasoning participation требует следующего этапа.
- External consciousness evaluator: scaffold есть, независимый blind evaluator ещё не реализован; P23 вместо него даёт измеримые learning/shadow/ablation diagnostics.

### Намеренно не реализуется как цель
- Полная биохимическая симуляция мозга.
- Огромная LLM как постоянный мозг.
- Постоянный LLM polling.
- Обучение весов после каждого цикла.
- IIT/Φ как доказательство сознания.
- Тяжёлая robotics/3D ради эффекта.

Каждый новый механизм должен быть: связан с циклом, наблюдаем, perturbable, ablatable, replayable и phone-safe.
