## Найденная проблема и исправление

### 1. Goal churn
Первоначальная версия пересоздавала goal почти на каждом тике из-за точного vector fingerprint. Это оказалось плохим жизненным циклом: память цели не успевала накопить прогресс. Алгоритм изменён на persistent goal object + bounded vector blending + revision только при устойчивом конфликте.

### 2. Premature skill isolation
Первоначально skill reuse требовал точного goal fingerprint. Это давало много skill creations и мало reuse. Reuse теперь допускается для доказанно успешного action-sequence класса, а не только для идентичного goal id.

### 3. Completion/restart edge
После completion goal не должен оживать автоматически в том же объекте. Исправлена lifecycle логика root/active goal selection.
