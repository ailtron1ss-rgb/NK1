# B284 Release Notes — Neural Autobiographical Identity Core

B284 adds a recurrent neural identity substrate integrated with the existing self/world/memory/goal/personality/action chain.

Major additions:
- recurrent identity latent;
- trait-specific neural value subspaces;
- autobiographical episode traces;
- slow identity revision;
- personality evidence bridge;
- action bias from learned identity;
- symbolic-ledger-free recall and causal ablation;
- persistence/migration and Core integration.

Validation:
- Typecheck PASS
- B284 standalone PASS
- ledger-free PASS
- Core/restart PASS
- B279–B283 regression PASS (targeted)

Important limitation: B284 is not a biological brain model and does not establish consciousness or phenomenal experience.
