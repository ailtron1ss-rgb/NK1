# B275 Release Notes

B275 adds a learned neural compositional policy layer on top of B274 verified skills.

Highlights:
- trainable action weights;
- recurrent action transitions;
- eligibility traces;
- outcome-driven plasticity;
- neural/self/personality context integration;
- composition of verified skills;
- independent verification and transfer;
- Core arbitration integration;
- migration and exact restart verification.

This release intentionally does not claim open-ended intelligence or consciousness.
