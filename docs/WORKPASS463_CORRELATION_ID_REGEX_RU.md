# WorkPass463 — исправление regex для ID корреляции

**Дата:** 2026-10-27  
**Статус:** исправление внесено; необходимо подтвердить повторный P23 CI на текущем HEAD.

WorkPass293 теперь запускается после регистрации отсутствующего npm-скрипта и дошёл до импорта `OutcomeVerificationService.ts`. Там был лишний уровень экранирования: класс регулярного выражения содержал буквальные двойные обратные слеши, и Node.js отвергал диапазон при компиляции.

Исправлено на реальный диапазон управляющих символов C0, DEL и C1. Валидация сохраняет fail-closed семантику: malformed correlation ID возвращает отказ, а не усекается в другой допустимый идентификатор.
