# WorkPass511 — release license readiness (обязательная ручная проверка)

## Назначение

Этот gate не определяет лицензию автоматически. Он не позволяет считать NeuroCore готовым к распространению, пока не подтверждены условия проекта, runtime, закреплённых npm-зависимостей, импортированных исходных архивов и обнаруженных LICENSE/NOTICE.

## Как закрыть блокер

1. Запустить npm run test:provenance-current для обновления CycloneDX SBOM и актуального отчёта SOURCE_PROVENANCE_LICENSES_WORKPASS70.json.
2. Просмотреть каждый архив и LICENSE/NOTICE по исходной лицензии и условиям распространения. Наличие файла LICENSE само по себе не является одобрением.
3. Проверить, что лицензия корневого проекта и runtime определена и совместима с предполагаемым распространением.
4. Проверить locked npm dependency inventory как полный набор. Если состав компонентов, версии, package URL или выражения лицензий меняются, fingerprint изменится и ревью нужно повторить.
5. В contracts/RELEASE_LICENSE_REVIEW.json заполнить каждую запись только после реальной проверки: status=approved, redistributionApproved=true, явный licenseExpression, reviewerType=human, имя проверяющего, timestamp и evidenceRef. Для inventory npm указать fingerprint, выведенный командой gate для текущего SBOM.
6. Повторить npm run audit:release-license-readiness. Gate должен пройти только после полного покрытия актуальной инвентаризации и всех явных решений.

## Текущее состояние на 27 октября 2026

Все решения намеренно оставлены pending. В provenance есть сторонние архивы, в которых автоматический инвентарь не обнаружил license/NOTICE среди верхнеуровневых файлов; это не означает, что они свободны от ограничений. Отдельно нужно определить политику лицензии самого NeuroCore и его runtime.

Пока gate не проходит, это корректный статус блокера. Не изменяйте статус на approved ради прохождения CI и не трактуйте этот механизм как юридическое заключение.
