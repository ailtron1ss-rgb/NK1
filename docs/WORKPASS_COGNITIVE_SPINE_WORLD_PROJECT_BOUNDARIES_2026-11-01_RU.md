# NK1 WorkPass — cognitive spine, world feedback and project-tool boundaries (2026-11-01)

## Protective resource gate

The cognitive spine scheduler now treats `protect` as a hard budget boundary for optional research, world rollout, shadow simulation and project operations. External urgency cannot bypass protection mode; core/reflex and governance handling remain outside this secondary-work scheduler. Opportunity and skip counters remain visible.

## World feedback integrity

Action outcomes are rejected before any ensemble, contextual or latent-world mutation unless the complete transition is structurally valid. Both WorldContext snapshots require bounded facts/events/object collections, finite metrics, valid tick values and monotonic before/after ticks.

The WorkPass39 reality-boundary fixture covers malformed object arrays and rewound world ticks, and verifies that rejected feedback leaves the world-learning snapshot unchanged. Simulator and device feedback are separated by a new observation tick to preserve B272's one-outcome-credit-per-tick rule.

## Project tool bridge

The project executor checks exact active-step tool binding before the project allowlist and destructive-action policy. The fixture explicitly binds its safe project step to the built-in `organism.project.context` reader, in operational mode with immediate checkpoints. A separate fixture binds a step to a deliberately destructive tool and verifies the project destructive-action guard rejects it before execution.
