# WorkPass449 — эпистемический журнал и ревизия убеждений

**Ветка:** `feature/memory`  
**Источник идей:** [QuixiAI/Hexis — Memory Architecture](https://github.com/QuixiAI/Hexis/blob/main/docs/concepts/memory-architecture.md), MIT.  
**Статус:** код и регрессия добавлены; runtime execution ещё не подтверждён.

## Изменение

`P65EpistemicLedger` различает наблюдение, вывод, убеждение, прогноз и контрфактическую гипотезу. Добавлен отдельный `reviseBeliefFromEvidence`: каждая ревизия связывается с конкретным evidence ID и источником, поддержка/противоречие попадают в ограниченную историю.

Уже применённый ID не учитывается повторно. Новый независимый источник изменяет уверенность в log-odds пространстве с учётом веса источника; повтор того же источника не повышает уверенность бесконечно. Противоречащие данные другого источника снижают уверенность вместо того, чтобы молча перезаписать исходное утверждение.

## Границы и интеграция

- Restore и live ingress проходят через существующий `PlainDataSnapshot` trust boundary.
- Убеждения, история источников, ключи evidence и ревизии ограничены по размеру; неизвестные/невалидные rows не становятся фактами.
- Schema v2 остаётся восстанавливаемой: старые записи получают консервативные значения provenance.
- Новый тест `p65-independent-evidence-revision.mjs` подключён к `test:p64:p65`.
- Из Hexis перенесён принцип аудируемой корректировки знания, а не чужая база данных/ORM; новых runtime-зависимостей нет.
