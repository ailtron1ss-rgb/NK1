# WorkPass496 — раздельная проверка памяти для русского и английского

**Дата:** 27 октября 2026 года  
**База:** ветка `workpass70-source`, SHA `c1bb9291aa5035b09f0acaa59b197d45b70bdb13`  
**Область:** офлайн-оценка извлечения воспоминаний и ворота продвижения. Алгоритм ранжирования не меняется.

## Что изменено

Существующий бенчмарк сравнивает гибридный поиск MemoryOS2 с корпусным BM25 и проверяет утечки между train/holdout, неизвестные метки, устаревшие и карантинные воспоминания, abstention и парные bootstrap-интервалы. При этом общий показатель мог скрыть ухудшение поиска на одном языке за счёт другого.

Добавлено явное поле языка каждого размеченного примера: `language = en | ru | other`. Язык берётся из набора разметки, не выводится из ответа модели или результата поиска. Если отмечена хотя бы одна строка, каждая принятая строка должна иметь языковую метку. Языковая метка включается в fingerprint набора, а fingerprint старых наборов без меток сохраняется прежним.

## Ворота продвижения

Для допуска к независимому рассмотрению требуется отдельно для английского и русского:
- минимум 2 train-запроса;
- минимум 8 отвечаемых holdout-запросов;
- минимум 2 явно неотвечаемых holdout-запроса;
- практический прирост recall и положительная нижняя граница парного bootstrap-интервала;
- отсутствие регрессии MRR по точечной оценке и доверительной границе;
- отсутствие небезопасных результатов и ухудшения отказа от неподдержанного ответа.

Пороговые минимумы нельзя снизить через параметры CLI. Метки `other` доступны для диагностики, но не заменяют ни русский, ни английский.

## Проверки и ограничения

Регрессии проверяют структуру отчёта и поведение ворот на синтетических фикстурах: RU/EN-страты, набор только на одном языке, неполные метки, корректная передача меток CLI и отказ при неизвестной локали. Это проверка инженерного контракта, а не доказательство реального улучшения памяти.

Алгоритм поиска в этом проходе не изменён; bootstrap-seeds не обучают его. Для решения о реальном продвижении нужен независимый, неизменяемый русско- и англоязычный holdout с происхождением данных и подтверждённой лицензией, а также положительный uplift с доверительной поддержкой по каждому языку.

Бенчмарк остаётся офлайн, не меняет живую память и не продвигает кандидата автоматически. `main` и опубликованный Release ZIP не затрагиваются.
