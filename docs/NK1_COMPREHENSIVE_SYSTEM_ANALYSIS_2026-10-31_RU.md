## 1. Введение и системный контекст

Проект **NK1** представляет собой комплексную кибернетическую систему воплощения цифровой личности Макисэ Курису на основе принципов теоретической нейронауки, когнитивной архитектуры двойного кодирования, динамического гомеостаза и многоуровневого моторно-эмоционального воплощения (Embodiment).

Данный документ консолидирует:
1. Оценку готовности всех 10 этапов Генерального плана (Master Plan 2026-10-30).
2. Анализ и адаптацию ключевых донорских open-source проектов (Letta, Mem0, CleanRL, Avalanche, River, OpenSCAD, Khronos glTF-Validator, Three.js VRM).
3. Анализ передовых научных исследований в области непрерывного обучения (continual learning), консолидации памяти, интринсивной мотивации и моторного воплощения.
4. Архитектуру физического и эмоционального воплощения Курису (3D-аватар, скелетный риг, кинематика IK, гардероб, эмоции и визуальные новелльные спрайты).
5. Карту связей между ветками репозитория и стратегию устранения десинхронизаций.

## 3. Анализ донорских проектов и их адаптация в архитектуру NK1

В соответствии с архитектурным принципом NK1, сторонние возможности интегрируются исключительно через **изолированные адаптеры**, предотвращающие появление дублирующих или конкурирующих ядер принятия решений.

```
       +-------------------------------------------------------------+
       |             NK1 Cognitive Kernel & Self-Model               |
       |               (Единый субстрат сознания Курису)             |
       +-------------------------------------------------------------+
                                      |
       +------------------------------+------------------------------+
       |                              |                              |
       v                              v                              v
+---------------+             +---------------+              +---------------+
| Memory Tier   |             | Learning Tier |              | Embodiment    |
| Adapters      |             | Adapters      |              | Motor Tier    |
+---------------+             +---------------+              +---------------+
| - Mem0        |             | - CleanRL     |              | - Three.js    |
| - Letta       |             | - Avalanche   |              | - @pixiv/vrm  |
| - Hexis       |             | - River Drift |              | - Planar IK   |
+---------------+             +---------------+              +---------------+
```

### 3.1. Mem0 & Letta (Многоуровневая память)
* **Mem0:** Адаптирован в качестве векторного графа ассоциативной долговременной памяти. Позволяет извлекать релевантные факты о связях Макисэ Курису с Окабэ, Дару, институтом Виктор Кондрия и исследованиями машины времени.
* **Letta (MemGPT paradigm):** Реализует трехуровневую иерархию памяти:
  1. *Рабочая память (Core Memory):* Персона, директивы самосознания, текущее эмоциональное состояние.
  2. *Архивная память (Archival Memory):* Неограниченное хранилище прошедших диалогов и событий с семантическим поиском.
  3. *Память воспоминаний (Recall Memory):* Временная линия сессий с казуальной привязкой.

### 3.2. CleanRL & Avalanche (Непрерывное обучение без катастрофического забывания)
* **Avalanche (ContinualAI):** Обеспечивает математический мониторинг метрик забывания (*backward transfer*) и пластичности (*forward transfer*). Гарантирует, что при усвоении новых знаний Курису не теряет базовые черты характера (научный скептицизм, смущение при похвалах, аналитический склад ума).
* **CleanRL:** Предоставляет легковесные, прозрачные реализации алгоритмов обучения с подкреплением (PPO/SAC) для адаптации параметров диалога к обратной связи собеседника.

### 3.3. River (Детекция концептуального дрейфа)
* Реализованы алгоритмы **ADWIN** (*Adaptive Windowing*) и **Page-Hinkley** для мгновенного обнаружения изменений в теме разговора или настроении пользователя, предотвращая зависание аватара в неактуальных эмоциональных паттернах.

### 3.4. Three.js & @pixiv/three-vrm (Моторное и визуальное 3D-воплощение)
* Адаптер трехмерного пространства обеспечивает:
  1. Загрузку стандартных аниме-моделей VRM (версий 0.x и 1.0) и GLB с поддержкой моделей до 90 МБ.
  2. Клиентское кэширование в IndexedDB для мгновенной загрузки без повторных скачиваний по сети.
  3. Процедурный синтез канонического 3D-аватара Курису при отсутствии внешнего файла.

## 4. Обзор современных научных исследований в архитектуре NK1

Архитектура системы опирается на актуальные фундаментальные исследования 2024–2026 годов:

1. **Комплементарные системы обучения (Complementary Learning Systems, CLS):**
   - Исследования *Kumaran et al.* и развитие двухкомпонентной теории гиппокампа и неокортекса. В NK1 гиппокампальный буфер быстро фиксирует эпизоды диалога, а ночная/фоновая консолидация переносит паттерны в неокортикальные обобщенные веса личности.
2. **Предиктивное кодирование и свободная энергия (Friston's Free Energy Principle):**
   - Курису воспринимает входные стимулы (текст, голос, видеокамеру) через призму минимизации ошибки предсказания. Неожиданные реплики вызывают повышение внимания (*salience*) и эмоциональный всплеск любопытства (*curiosity drive*).
3. **Воплощенное познание (Embodied Cognition):**
   - Ментальное состояние напрямую транслируется в микродвижения тела (наклон головы при размышлении, скрещивание рук на груди при споре, прикосновение к подбородку, учащенное моргание при смущении).

## 5. Архитектура 3D-воплощения: канонический аватар Макисэ Курису

### 5.1. Канонические визуальные элементы
* **Волосы:** Характерный каштаново-рыжий оттенок (`#7A1C16` / `#8B251E`), длинные пряди до пояса, боковые обрамляющие локоны и белые перекрестные заколки с обеих сторон головы.
* **Лицо и взгляд:** Фиолетовые миндалевидные глаза (`#4A3B69` / `#5A4580`), тонкие выразительные брови, градиентный аниме-румянец на щеках.
* **Гардероб (модульная система сменной одежды):**
  1. *Лабораторный халат (Lab Coat):* Белый развевающийся халат поверх коричневого кардигана — визитная карточка «LabMem 004».
  2. *Повседневный (Casual):* Расстегнутый коричневый удлиненный кардиган (`#8C6338`), белая рубашка с синей каймой и распущенный красный галстук, черные шорты с высокой талией и двойным ремнем, черные колготки/чулки и полусапожки.
  3. *Худи / Домашний (Hoodie):* Свободная уютная толстовка для неформального общения.
  4. *Строгий костюм (Formal):* Темный костюм для научных конференций и симпозиумов.

### 5.2. Моторный контроль и скелетная кинематика
* **Двусторонняя аналитическая инверсная кинематика рук (Bilateral Planar IK):**
  - Расчет углов плеча и предплечья по целевым координатам ладоней в реальном времени.
  - Поддержка ключевых канонических жестов:
    - `thinking_chin` — ладонь у подбородка, легкий наклон головы.
    - `arms_crossed` — скрещенные на груди руки (характерная защитная поза цундэрэ).
    - `whiteboard` — указательный жест при объяснении физических теорий.
* **Автономные движения и микро-анимации:**
  - Сакадические движения глаз (случайный микродрейф фокуса).
  - Спонтанное моргание (интервал 3-6 секунд с защитой от залипания).
  - Дыхательный цикл (микродвижения грудной клетки и плеч).
  - Вторичная физика волос и лацканов халата при поворотах головы.

## 6. Межфилиальная топология и координация веток

В репозитории сосуществуют две линии разработки:
1. **Релизная ветка (`main`):** Легковесная конфигурация, содержащая релизные детерминированные скрипты, манифесты аудита, контрольные суммы SHA-256 и документацию.
2. **Исходные функциональные ветки (`workpass70-source`, `origin/work/...`):** Полные деревья исходного кода (React 19, TypeScript, Vite, TailwindCSS, Three.js, runtime Neuro-Kurisu).

**Стратегия интеграции:** Все ценные наработки из рабочих веток переносятся и адаптируются в релизное русло в виде проверенных, автономных и готовых к интеграции модулей без засорения репозитория временными невоспроизводимыми бинарными артефактами.
