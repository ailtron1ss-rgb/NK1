# WorkPass406 — устойчивые метрики развития навыков

## Задача

Показывать не только среднее изменение и семейные confidence bounds, но и устойчивую картину по разным задачам. Обычное среднее может чрезмерно зависеть от выброса; один общий показатель также скрывает различия между успешностью задачи, качеством навыка и качеством траектории.

## Что внедрено

Модуль `runtime/neuro-kurisu/src/organism/learning/LearningRobustMetrics.ts` вычисляет для каждого split отдельно:

- task-balanced IQM до и после изменения навыка для `taskSuccess.passRate`, `skillQuality.aggregate` и `trajectoryQuality.aggregate`;
- delta IQM;
- парную вероятность улучшения: внутри каждой задачи победа кандидата даёт 1, равенство — 0.5, ухудшение — 0; доли усредняются по seed внутри задачи, затем по задачам с одинаковым весом;
- число задач и согласованных trial-пар.

IQM рассчитывается как интеграл эмпирической квантильной функции на центральном интервале 25–75%; дробные граничные веса устраняют скачок от округления при малом количестве задач. Усреднение seed внутри задачи перед IQM не даёт задачам с большим количеством запусков получить больший вес.

## Встройка в P23

`compareMatchedIndependentEvaluations(...)` возвращает `learningRobustDiagnostics` для validation и holdout. Перед расчётом уже проверены fingerprints, парность task/trial/seed, split, окружение, plan и независимые evidence bindings. Метрики сделаны наблюдаемыми для анализа прогресса, но помечены `diagnosticOnly: true` и **не влияют на `eligible`, не заменяют confidence intervals и не открывают путь к promotion**. Авторитетными остаются существующие safety, provenance, семейное покрытие, paired-seed confidence и signed-evidence gates.

Входы проходят через `snapshotPlainData`; дубликаты, отсутствующие пары, небезопасные идентификаторы и оценки вне диапазона [0, 1] отвергаются. Все вычисления детерминированы и не требуют новой runtime-зависимости.

## Исследовательская основа

- [Google Research RLiable](https://github.com/google-research/rliable) рекомендует IQM, вероятности улучшения и оценку неопределённости наряду со средним.
- [Hermes Agent Self-Evolution](https://github.com/NousResearch/hermes-agent-self-evolution) мотивирует разделение генерации, анализа неудачных траекторий, независимой оценки и promotion gates.

Это адаптация идеи к существующей TypeScript-архитектуре NK1, а не копирование исходного кода или установка чужого framework. Используемая здесь парная вероятность улучшения и task-balanced IQM — дополнительные описательные метрики, не полная реализация RLiable и не статистическое доказательство прироста.

## Проверки и границы вывода

Регрессия `tests/workpass406-learning-robust-metrics.mjs` охватывает IQM/delta, парные tied/win/loss результаты, инвариантность к порядку строк, отсутствующие пары, выход scores за диапазон и non-invocation враждебного getter. Тест подключён к существующему агрегатному скрипту `npm run test:p23:learning`.

Код не заявляет measured learning uplift. Тест/TypeScript и CI считаются подтверждёнными только после успешного выполнения на точном HEAD; GitHub Actions ранее завершались до доступных runner steps/logs.
