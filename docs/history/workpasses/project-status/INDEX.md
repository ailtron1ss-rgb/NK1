## Evidence and reversibility

- Each archive copy was read back from GitHub and had the exact same content and Git blob SHA as its source before source deletion.
- Content SHA-256, byte size, copy commit and source-removal commit are recorded in [`relocation-manifest.json`](relocation-manifest.json).
- For live project status, use the [project map](../../../PROJECT_MAP_AND_ORDERING.md) and current branch/PR/exact-head CI, not these archived reports.
- Only these three Markdown files were moved. Associated JSON snapshots remain in place until their own target/reference review is done.

The batch preserves historic evidence; it does not imply every historical status file has been reviewed or that the release archive is refreshed.
