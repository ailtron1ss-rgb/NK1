## 2. Архитектура единой системы мультимодального воплощения (2D / 2.5D / 3D)

Переключение визуального представления персонажа организуется через компонент `app/src/components/AvatarStage.tsx` на основе единого протокола моторного интента `kurisu_embodiment_intent` v1:

```text
       ┌────────────────────────────────────────────────────────┐
       │             Unified Cognitive Substrate                │
       │       (Эмоция, Энергия, Возбуждение, Таймлайн речи)      │
       └───────────────────────────┬────────────────────────────┘
                                   │
                                   ▼
                   kurisu_embodiment_intent (v1)
          (Единый нормализованный контракт моторного интента)
                                   │
        ┌──────────────────────────┼──────────────────────────┐
        ▼                          ▼                          ▼
 ┌──────────────┐          ┌──────────────┐          ┌────────────────┐
 │ 2D Режим     │          │ 2.5D Режим   │          │ 3D Режим       │
 │ Live2DViewer │          │ KurisuOriginal│         │ Avatar3DStage  │
 │ (Cubism SDK) │          │ Stage (SVG)  │          │ (Three.js/VRM) │
 └──────────────┘          └──────────────┘          └────────────────┘
```

### Спецификация режимов:
1. **2D Mode (Live2D Cubism):**
   - Рендерер: `app/src/components/Live2DViewer.tsx`.
   - Текстурные атласы 4096 (десктоп) и 2048 (мобильные устройства).
   - Точная графемно-виземная синхронизация губ по таймлайну браузерного/Termux TTS.
   - Использование анимационных токенов (`motionToken`) для предотвращения зацикливания движений.
2. **2.5D Mode (Vector SVG Rig):**
   - Рендерер: `app/src/components/KurisuOriginalStage.tsx`.
   - Иерархическая многослойная сцена из векторных SVG-элементов.
   - Независимое управление углами наклона конечностей и головы с псевдообъемной глубиной (параллакс).
   - Локальная кастомизация палитры (волосы, глаза, лабораторный халат) без перезагрузки сцены.
3. **3D Mode (Three.js WebGL / VRM / glTF):**
   - Рендерер: `app/src/components/Avatar3DStage.tsx`.
   - Процедурный character lit-mesh по умолчанию (голова, волосы, одежда, ботинки, окружение).
   - Локальный импорт пользовательских файлов `.vrm` / `.glb` размером до 90 МБ с хранением в IndexedDB (без отправки на сторонние сервера).
   - Автоматический маппинг morph targets для формы рта (виземы) и мимики, а также Humanoid-скелета для анимационных клипов.
4. **Адаптивный диспетчер и бесшовное переключение:**
   - Переключение между 2D, 2.5D и 3D происходит «на лету» без разрыва контекста разговора, потери эмоции или сброса фазы речи.
   - Динамический контроль частоты кадров: при падении FPS < 30 или нехватке VRAM интерфейс автоматически выполняет мягкое понижение режима (3D → 2.5D → 2D).

## 3. Этапы доведения системы до 100% готовности

1. **Фаза 0: Консолидация кодовой базы, инфраструктуры и лицензий**
   - Инвентаризация 400+ веток, разрешение конфликтов слияния стека Hexis с `workpass70-source`.
   - Устранение 135 лицензионных флагов в `tools/audit-release-license-readiness.mjs`.
   - Обеспечение 100% зеленого статуса всех CI workflows на едином каноническом HEAD.
2. **Фаза 1: Интеграция локальной модели в продуктовый цикл**
   - Включение `OpenAICompatibleLocalChatProvider` в `OrganismCore` с жестким бюджетированием токенов и таймаутами.
   - Верификация матрицы отказов (503, timeout, отмена пользователем, восстановление после сбоя).
3. **Фаза 2: Качественный прорыв в памяти (MemoryOS2)**
   - Фиксация двуязычного RU/EN holdout-корпуса.
   - Реализация семантического векторного поиска в `MemoryOS2` с доказанным `recallDelta > 0` относительно baseline.
4. **Фаза 3: Непрерывное обучение и защита от забывания**
   - Проведение испытаний `IndependentSkillCandidateEvaluator` на независимых контрольных задачах.
   - Идемпотентное продвижение навыков с фиксацией причинно-следственной связи (causal credit).
5. **Фаза 4: Верификация внешних действий и устойчивость к сбоям**
   - Полное закрытие ACK-gap в `ActionGateway` и проверка последствий методом read-after-write.
6. **Фаза 5: Мультимодальное воплощение (2D / 2.5D / 3D)**
   - Доработка `AvatarStage.tsx` и обеспечение сквозного проброса `kurisu_embodiment_intent` во все 3 рендерера.
   - Оптимизация работы WebGL/Live2D на мобильных и десктопных браузерах.
7. **Фаза 6: Автономная жизнедеятельность и 72-часовой Soak Test**
   - Проведение непрерывного 72-часового стресс-теста автономной работы организма без деградации памяти и накопления ошибок.
8. **Фаза 7: Финализация релиза**
   - Генерация полного SBOM, чистая установка зависимостей, формирование и верификация опубликованного Release ZIP архива с SHA-256.
