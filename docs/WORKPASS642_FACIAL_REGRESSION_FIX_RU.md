# WorkPass642 — Исправление регрессионной проверки семантической мимики

## Причина

В Actions run `41042075160` шаг `Validate 3D renderer integration and recovery` завершился ошибкой в тесте `avatar-3d-stage.test.mjs`. Проверка искала строгое текстовое представление `composeFacialWeights(expressions,speechVisemes)`, но реализация корректно форматирует аргументы с пробелами и переносами строк.

## Изменение

- Сделана проверка whitespace-tolerant: пробелы и переносы между аргументами не влияют на результат.
- Production runtime не изменялся: вызов `composeFacialWeights(expressions, speechVisemes)` уже выполнял требуемую композицию.
- Проверка по-прежнему требует правильный порядок аргументов и сам вызов функции; она не ослаблена до проверки одного лишь имени.

## Валидация

- Предыдущий Actions run подтвердил прохождение preflight и model-validation тестов (12/12), но остановился на указанном статическом regression test (11/12 в группе Avatar3DStage).
- Исправление отправлено отдельным commit WorkPass642.
- Новый Actions run для нового SHA требуется проверить; успешная валидация пока не заявляется.
- Реальный browser/device E2E на наборах VRM 0.x, VRM 1.0 и GLB остаётся отдельным незакрытым gate.
