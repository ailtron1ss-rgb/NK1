# WorkPass483 — Неизменяемые ID трасс доказательств

**Дата:** 2026-10-27  
**Статус:** код и регрессионные сценарии закоммичены; выполнение тестов в этом проходе не подтверждено.

## Что защищено

1. `SourceMonitor.record()` не позволяет повторной записи с существующим ID заменить первоначальную трассу. Идентичный повтор становится no-op; конфликтующее содержимое увеличивает счётчик конфликтов.
2. `SourceMonitor.restore()` применяет то же правило к сохранённому состоянию: сохраняет первую трассу для ID, отбрасывает конфликтующие дубликаты и учитывает конфликты восстановления.
3. Тест `hexis-canonical-evidence-bridge.mjs` покрывает повторное использование ID и конфликтующий дубликат в снимке.
4. Тест `hexis-server-smoke.mjs` отправляет через HTTP-ingress повторный ID с подменённым `sourceId` и требует, чтобы исходная каноническая линия не добавлялась повторно.

## Граница гарантии

Эти проверки обеспечивают стабильность идентичности трассы и препятствуют подмене происхождения через повторный ID. Они **не доказывают подлинность самого сенсора/источника или истинность наблюдения**. SHA-256 связывает переданное содержимое с fingerprint, но сам по себе не удостоверяет, кто создал содержимое.

## Проверка

Файлы тестов повторно прочитаны из GitHub после изменений. В рамках этого прохода локальный запуск не выполнялся; успешный CI не заявляется. Следующий шаг — провести реальные тесты в Node.js, затем измерить, улучшает ли извлечение из `MemoryOS2` точность ответов на независимом holdout-наборе.
