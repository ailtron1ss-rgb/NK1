# WorkPass452 — контекстная калибровка эмоциональных тенденций

**Ветка:** `feature/emotions`  
**Источник идеи:** [QuixiAI/Hexis — Identity and Worldview](https://github.com/QuixiAI/Hexis/blob/main/docs/concepts/identity-and-worldview.md) и [Self-Development](https://github.com/QuixiAI/Hexis/blob/main/docs/concepts/self-development.md), MIT.  
**Статус:** механизм и регрессия добавлены; точный тестовый прогон не подтверждён.

## Изменение

`EmotionAppraisalEngine` хранит второй вид калибровки результата: не только глобально по действию, но и по сочетанию action × emotion label × homeostatic-pressure band (low/medium/high). Если текущий эмоционально-физиологический контекст имеет собственные доказательства, результат из другого контекста не изменяет его приоритет.

Существующая глобальная статистика сохранена для обратной совместимости. Старые данные без контекстной истории используют меньший коэффициент влияния; при наличии контекстных данных действие без matched-контекста не получает глобальную награду в другом состоянии.

Результат можно явно привязать к `emotionId`. Несуществующий ID отклоняется — reward не должен случайно обучить не тот эпизод.

## Цель архитектуры

Эмоциональная оценка должна влиять на внимание, выбор исследования/проверки/отдыха и память, однако это лишь регуляторные сигналы, а не безусловные команды. Повторный полезный исход в состоянии стресса не должен автоматически доказывать, что то же действие полезно в спокойном состоянии.
