## Реально реализовано в коде

1. **Причинная атрибуция временного возврата.** `CanonicalTemporalCreditAuthority` больше не включает outcome, адресованный другому `decisionId`. Переполнение журнала незакрытых решений не уничтожает старое решение молча: оно получает явную запись `expired` с нулевой eligibility/confidence и не обучает политику.
2. **Проверка независимости Reafference.** Успешный `match` теперь требует положительного числа независимых источников и reconciliation со статусом `supported` или `corroborated`; высокий score сам по себе не создаёт независимое свидетельство.
3. **Внешний результат действия в единственной канонической памяти.** Только для точного решения, разрешённой квитанции, пригодного независимого свидетельства и не повторного события `OrganismCore` записывает provenance-linked эпизод `verified-external-action-outcome` в MemoryOS2. Эпизод содержит связи decision/execution/observation, lineage/independence, ожидаемое и наблюдаемое условие, цель и направление результата. Тот же outcome один раз обновляет P33 через стабильный evidence ID.
4. **Ранжирование поиска по типу вопроса.** MemoryOS2 получает ограниченную двуязычную подсказку намерения запроса (событие, инструкция, личность/предпочтение, цель, причина/последствие, факт) и добавляет небольшой bounded bonus только к совпадающим kind/context; lexical fusion остаётся активной.

## Целевые результаты

- Тест временного кредита подтверждает отсутствие перетекания награды между двумя решениями и явное нулевое завершение при переполнении.
- Тест Reafference codec отклоняет высокий match score при нулевом независимом подтверждении и неизвестном/unresolved reconciliation.
- Интеграционный сценарий проходит от внешнего результата через durable episodic memory и P33 до перезапуска без дублирования.
- Шесть контролируемых сценариев выбора типа памяти проходят для запросов на русском/английском.
- Общий memory benchmark всё ещё показывает `recallDelta=0`; это **не** считается улучшением общего качества поиска и кандидат не продвигается.

## Что не закрыто

- Production Vite build и интерактивный browser/Live2D/Legacy E2E после установки зависимостей.
- Долгий запуск с реально настроенным языковым провайдером, настоящий внешней адаптер/device receipt, reconnect/replay и ambiguous-result reconciliation.
- Независимый размеченный holdout памяти с положительным измеримым uplift.
- Точная audio-buffer/phoneme/viseme синхронизация Live2D; текущая озвучка/моделирование рта остаются приближёнными.
- Local inference на целевом хосте, clean-room rollback, полный nested-source license/provenance review и soak.

Подсистемы памяти и личности не дублировались: память остаётся у MemoryOS2, профиль интересов — у P33, временной кредит — у CanonicalTemporalCreditAuthority, Reafference — у существующего canonical codec/core. Этот проход не доказывает субъективное сознание и не означает готовность к релизу.
