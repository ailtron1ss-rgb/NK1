# NK1 — Реестр и панель отслеживания прогресса (2026-10-30)

## Общие сведения

Документ фиксирует текущий статус выполнения 16 фаз (160 шагов) мастер-плана **NK1 / Neuro Kurisu**.
Все статусы продвигаются строго по каноническому протоколу: `PLANNED` → `IMPLEMENTED` → `TESTED` → `INTEGRATED` → `MEASURED` → `RELEASED`.

Правило зачёта: шаг или фаза считается пройденной только при наличии конкретного изменения, зафиксированного SHA, успешной регрессионной проверки и доказанного результата. При отсутствии какого-либо из элементов устанавливается статус `UNVERIFIED` или `PENDING`.
