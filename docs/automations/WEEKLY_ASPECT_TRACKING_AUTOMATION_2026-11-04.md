# Weekly tracking automation — 75 аспектов NK1

Артефакт для настройки еженедельного отслеживания. **Не развёрнут** — требует подтверждения
владельца. Создаётся как OpenHands automation (prompt preset, cron).

## Поведение

- **Триггер:** cron, каждый понедельник 09:00 UTC (`0 9 * * 1`).
- **Репозиторий:** `ailtron1ss-rgb/NK1`, ветка `workpass70-source` (свежий source head).
- **Что делает:** читает `docs/nk1-aspect-progress.json`, запускает `npm run aspect:progress:json`,
  сверяет статусы с фактическими артефактами доказательств, готовит недельный дайджест и —
  только при наличии реального доказательства — открывает один PR с обновлением статусов.
- **Ограничение:** статус аспекта не поднимается без связанного артефакта доказательства
  (тест, CI run, E2E-трасса, holdout-отчёт). Если изменений нет — PR не открывается.

## Prompt (тело автоматизации)

```text
Ты ведёшь недельное отслеживание 75 аспектов NK1/NeuroCore в репозитории ailtron1ss-rgb/NK1
(ветка workpass70-source).

1. Обнови источник: git fetch origin workpass70-source и зафиксируй точный head SHA.
2. Прочитай docs/nk1-aspect-progress.json — это единственный источник истины по статусам.
3. Запусти `npm run aspect:progress:json` и зафиксируй отчёт (по волнам и общий).
4. Для каждого аспекта со статусом IN_PROGRESS или BLOCKED проверь, есть ли у него связанный
   артефакт доказательства (ссылка на тест, CI run, E2E-трассу, holdout-отчёт) и актуален ли он.
   Проверь также аспекты, у которых все зависимости PASS и которые поэтому стали actionable.
5. Подготовь краткий дайджест на русском: сколько аспектов PASS по волнам, что изменилось за
   неделю, какие аспекты стали actionable, какие BLOCKED и почему.
6. Если и только если появилось реальное доказательство — открой ОДИН PR, который обновляет
   docs/nk1-aspect-progress.json: переносит аспекты в PASS/IN_PROGRESS/FAIL и прикладывает ссылку
   на артефакт в поле evidence. Один аспект — одна запись evidence минимум.
7. НИКОГДА не поднимай статус без артефакта доказательства. Проходящий unit-test, существующий
   файл или число модулей не являются доказательством. Если ничего не изменилось — не открывай PR
   и просто опубликуй дайджест.
8. В конце отчёта укажи точный head SHA и, если PR создан, его номер.

Ограничения: не удаляй ветки, не переписывай историю, не меняй код вне трекера и связанных
docs, не заявляй субъективное сознание или production-readiness.
```

## Создание (prompt preset)

```bash
OPENHANDS_HOST="https://app.all-hands.dev"
curl -X POST "${OPENHANDS_HOST}/api/automation/v1/preset/prompt" \
  -H "Authorization: Bearer ${OPENHANDS_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "NK1 weekly 75-aspect tracking",
    "prompt": "<prompt выше>",
    "trigger": {"type": "cron", "schedule": "0 9 * * 1", "timezone": "UTC"},
    "repos": [{"url": "ailtron1ss-rgb/NK1", "provider": "github", "ref": "workpass70-source"}],
    "timeout": 1800
  }'
```

## Стоимость и альтернатива

- Это LLM-driven prompt preset: один прогон в неделю (~4/месяц), бюджет незначителен.
- Если нужен полностью детерминированный вариант без LLM, его можно оформить как
  plugin-spec automation с `entrypoint.runner: "script"`, который только запускает
  `npm run aspect:progress:json` и публикует отчёт; но сверка доказательств требует суждения,
  поэтому по умолчанию предложен prompt preset.
- Требуется подтверждение владельца перед созданием (внешний ресурс).
