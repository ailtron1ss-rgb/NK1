# OmeStro №5 — Cognitive Immune System

## Роль в NK1

Пятый элемент OmeStro расширяет существующий `CognitiveImmuneSystem`, а не создаёт второй независимый механизм доверия. Контур запускается из канонического цикла `OrganismCore` после обновления P65.

## Источники наблюдений

- **P65EpistemicLedger:** жизненный цикл убеждений, подтверждённость, разрешённые прогнозы и ошибка прогнозирования.
- **ContradictionReservoir:** число и доля открытых противоречий.
- **ProceduralSkillLibrary:** устойчивость только уже накопивших достаточную выборку навыков.

## Достоверность измерения

Результат содержит `coverage01` и `healthStatus`. Числовой балл без достаточного числа измерений не трактуется как здоровое состояние: при coverage ниже 0.5 статус — `unknown`. Калибровка использует до 16 последних разрешённых прогнозов P65; глобальное среднее применяется только как совместимый fallback, если сохранённой когорты недостаточно.

## Шесть сигналов здоровья

1. Устаревшие/истёкшие убеждения.
2. Накопление открытых противоречий.
3. Ошибка калибровки прогнозов.
4. Деградация зрелых процедурных навыков.
5. Высокая уверенность при недостаточной поддержке.
6. Нестабильность оценок уверенности в последних эпистемических записях.

## Диагностируемость и аудит

Каждый сигнал хранит ограниченный список ссылок на реальные ID исходных записей P65, ContradictionReservoir или ProceduralSkillLibrary, которые вызвали тревогу. Для открытия, эскалации, автоматического/ручного восстановления, подтверждения или отклонения сохраняется отдельное событие. Журнал ограничен 128 событиями, ссылки — 12 на событие/сигнал. События переживают checkpoint/restore; старые checkpoints мигрируют с пустым журналом.

## Защита от ложных решений

- Один аномальный тик не создаёт тревогу: требуется как минимум два последовательных наблюдения.
- Метрики с недостаточным числом примеров помечаются невалидными и не ухудшают общий балл.
- Пороговые превышения создают объяснимые сигналы `review` или `critical`; baseline строится по ограниченной недавней истории.
- Повторный или устаревший тик игнорируется: одно наблюдение может дать только один вклад в streak.
- Неизмеримая метрика не считается здоровой и не участвует в автоматическом закрытии сигнала.
- Нестабильность уверенности оценивается как сдвиг среднего между двумя последовательными временными когортами P65, а не как обычное разнообразие разных утверждений.
- Источники и записи P65/резервуара/навыков остаются неизменными.
- Система не удаляет память, не переписывает убеждения и не понижает trust score автоматически.
- При активном критическом сигнале блокируются автоматическое продвижение обычных навыков в `habit`, составных навыков в `reusable`, активация новых вариантов и повышение fallback-инструмента до основного. Сбор исходов/evidence и demotion/rollback продолжаются; gate переживает checkpoint и снимается после восстановления.
- При активном критическом сигнале контур временно блокирует только автоматическое продвижение процедурных навыков в `habit`. Сбор исходов, накопление evidence и понижение деградировавшего навыка продолжаются; восстановление сигнала снимает блокировку.
- Подтверждение, отклонение как false-positive и признание восстановления фиксируются отдельной рецензией с автором и ссылкой на доказательство.

## Надёжность и восстановление

Состояние монитора хранится внутри snapshot существующего CognitiveImmuneSystem. История выборок ограничена 64 элементами, история сигналов — 64. Старые checkpoints без поля `health` восстанавливаются с нейтральным состоянием; P65 и остальные подсистемы не мигрируют и не переписываются.

## Проверка

Запуск: `npm run test:cognitive-immune-health`

Тест проверяет доказательные ссылки из реальных ledger IDs, последовательность audit events, восстановление истории и лимиты журнала; также проверяет здоровый baseline, единичную аномалию, устойчивую деградацию по нескольким независимым осям, review без мутации исходных данных, повторные/устаревшие тики, отсутствие ложного восстановления при неполных данных, обновление подтверждённых сигналов без дубликатов, временной сдвиг уверенности, повреждённые checkpoints, pause/resume продвижения навыков и ограничение истории, coverage/unknown health, недавнюю когорту прогнозов, а также блокировку и восстановление всех путей promotion для обычных и составных навыков.
