# Что ещё полезно интегрировать из четырёх исходных архивов — WorkPass45

Этот список не означает, что 22 исходных проекта были полностью влиты в runtime. Это остаточная матрица полезных механик, сопоставленная с текущими владельцами Курису. CSV содержит путь вложенного архива, приоритет, состояние, цель, критерии принятия и ограничения каждого решения.

## Сначала — P0/P1

1. **WILL:** сейчас базовый ActionGateway→outcome→CEF→external evidence путь усилен, но нужен реальный delayed observation после reconnect и связывание с `ReafferenceEvidenceCodec`/`CanonicalTemporalCreditAuthority` без повторного reward.
2. **Lumina:** candidate memory, dreaming/idle consolidation, temporal decay и staged toolmaker approval. Встраивать только в `MemoryFabric`/консолидационный scheduler/существующий tool registry.
3. **Hexis + Mem0:** supersession/revert, entity extraction/merge/conflict, provenance и migration semantics. Единая запись только через `MemoryFabric.applyLifecycleCommand` и `MemoryOS2`.
4. **Microsoft Agent Framework + OpenAI Agents SDK:** typed middleware/tripwires, pre/post tool guards, handoff/resume. Сначала дифференциально доказать gap; не добавлять второй workflow engine.
5. **OpenClaw + Hermes:** channel pairing/auth, session resume, approval and browser/device permissions. Нужна file-level проверка конкретных участков и лицензий, не bulk merge.
6. **llama.cpp:** запустить настоящий локальный inference, streaming/cancel и профили latency/RAM на целевой машине. Адаптер уже есть, факт работы модели на target host не доказан.

## Затем — проверяемые эксперименты

7. **Chroma + FAISS:** только read-only retrieval candidates за одним интерфейсом памяти. Независимый labelled temporal holdout обязателен; сейчас measured recall uplift нулевой — не продвигать.
8. **DSPy + Agent0:** офлайн оптимизация prompts/programs и curriculum/task generation в isolated lab, frozen baseline и независимая evaluation split.
9. **Hyperon/MeTTa:** исследовательский symbolic adapter на отдельной песочнице для ограниченной задачи; не новый production belief engine.
10. **AutoGPT:** только после точечной проверки лицензии конкретного файла и зависимостей. AutoGen, Langroid, OWL и PocketFlow — reference для сообщений, делегации, поиска и graph/retry flow, только если будет измеримый gap.

## Только provenance или инженерный процесс

- Два архива Letta — маленькие пересекающиеся снимки/документация; фиксировать origin/hash, не считать самостоятельной когнитивной реализацией.
- Superpowers — workflow улучшения разработки/отладки; не переносить в runtime и не считать capability.

## Новое в WorkPass45 относительно остатка

В этом проходе не копировались внешние project source files. Были интегрированы механики в канонический код Курису: provider reconciliation, local camera receipt sidecar, canonical ActionGateway camera ownership, stable-key HTTP guard и тесты. Остальные источники остаются в статусах и с гейтами в `SOURCE_INTEGRATION_REMAINDER_WORKPASS45.csv`; это намеренно предотвращает ложное заявление о массовой интеграции, которой фактически не произошло.

## Правило следующих проходов

Для каждого будущего заимствования обязательно записывать: исходный архив/путь/хеш, лицензию, текущий аналог в Курису, конкретный отсутствующий механизм, место встраивания, единичного владельца состояния, миграцию/rollback, тест реального поведения, измеримый эффект и решение `promote/adapt/reject`. Не переносить код только по сходству названия функции.
