## Что изменено

Добавлен `src/organism/cognition/InternalDialogueEngine.ts` — ограниченный цикл внутреннего пересмотра решения. Он проходит шесть ролей: framing, сравнение гипотез, критик, аудит доказательств, метакогнитивная калибровка и синтез. Это не пользовательский диалог и не транскрипт скрытого рассуждения: наружу возвращаются короткие аудируемые заметки, оценки доказательной базы и список нерешённых вопросов.

Движок:
- сравнивает максимум 12 гипотез и принимает не более 96 записей доказательств за цикл;
- связывает подтверждающие и опровергающие данные с конкретными гипотезами;
- различает типы данных: наблюдаемый исход весит больше, чем прогноз; память и цели не считаются самостоятельным подтверждением;
- не позволяет дублирующимся идентификаторам доказательств искусственно увеличивать поддержку;
- вычисляет покрытие доказательствами, конфликт, неопределённость и относительную уверенность ранжирования;
- ограничивает число внутренних проходов 3–6 и фильтрует явные маркеры секретов/контактных данных из вопросов;
- при совпадении одного evidence ID в списках подтверждений и опровержений выбирает консервативную трактовку — опровержение;
- считает покрытие по каждому кандидату один раз, не начисляет бонус независимости за противоречия;
- при недостатке доказательств рекомендует проверить или исследовать пробел, а при высокой когнитивной нагрузке — приостановить углубление.

## Интеграция

`LanguageOrgan.ts` вызывает обзор в `buildCognitiveProposalPrompt` непосредственно перед созданием языкового предложения. `CognitiveEventEvidenceBridge.ts` подключает к нему необязательный снимок канонического `CognitiveEventFabric`: результаты связываются с гипотезой только при наличии явного parent-edge к действию и распознаваемого типа действия. Поздние внешние наблюдения требуют точной цепочки `tool-action → tool-outcome → external-evidence`, совпадающего execution ID, независимого `sourceId`/`independenceKey` и статуса corroborated/contradicted.

Эвристический перенос `lastActionSuccess` на совпавшее название действия удалён. Если вызывающий код не передаёт снимок CEF, обзор остаётся работоспособным, но использует лишь слабые прогнозные данные и явно добавляет нерешённый вопрос об отсутствии причинного результата. Передача снимка в каждый реальный production-вызов ещё не подтверждена.

Обзор помечен как advisory-only. Он не исполняет инструменты, не меняет выбранное действие и не заменяет полномочия `OrganismCore` или существующих шлюзов безопасности. Постоянный журнал метакогнитивных результатов и ночная консолидация ещё не реализованы.

## Регрессии

Добавлен `tests/internal-dialogue-workpass319.mjs` с проверками:
- связывания outcome по явной связи `action → outcome`;
- связывания позднего независимого наблюдения по точной цепочке receipt;
- отклонения события с отсутствующим parent action или `independenceKey`;
- сравнения подтверждённых исходов с кандидатом, поддержанным только предсказанием;
- противоречащих данных и отсутствия явных подтверждений;
- пустого набора кандидатов и паузы при высокой когнитивной нагрузке;
- ограничения числа проходов, невалидного ввода и дублирующихся идентификаторов;
- фильтрации очевидных приватных строк;
- наличия обзора в `buildCognitiveProposalPrompt`, сохранения уже выбранного действия и отсутствия чувствительных фактов в prompt.

Команда `test:internal-dialogue-workpass319` добавлена в `runtime/neuro-kurisu/package.json` и в цепочку `test:rebuild-recovered`.

## Проверки и ограничения

- Локальный контрактный harness движка прошёл на Node.js 22.16.0; в тест добавлены проверки перекрытия подтверждающих/опровергающих ID, корректного coverage и отсутствия бонуса за источники противоречий.
- Изолированный harness скопированного evidence bridge прошёл с искусственным CEF snapshot: проверены прямой parent-edge, позднее независимое наблюдение, отсутствие `independenceKey` и висячая связь с действием.
- Полный интеграционный тест из точного checkout ветки не был исполнен в этой среде: клонирование GitHub завершилось ошибкой разрешения DNS.
- На момент фиксации draft PR #111 набор GitHub Actions для HEAD находился в состоянии `queued`, а combined commit status не содержал результатов. Это не является успешным CI.
- TypeScript typecheck, запуск полного `test:rebuild-recovered`, проверка реального runtime-вызова на данных организма, runtime performance, независимая калибровка и сборка release ZIP остаются непроверенными.
- Никакого прироста общей интеллектуальной эффективности, улучшения обучения или субъективного сознания не заявляется.

## Следующий технический шаг

Следующий шаг — передать снимок `CognitiveEventFabric` из реального вызова `OrganismCore` при каждом построении когнитивного предложения, затем добавить persistence/schema migration для компактных review receipts. После подтверждения exact-head typecheck и интеграционных тестов проверить calibration, decision regret и переносимость на paired seeds с неизменяемым holdout. До этих измерений обзор должен оставаться advisory critic.
