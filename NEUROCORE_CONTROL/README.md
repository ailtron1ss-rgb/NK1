# NeuroCore control record

This directory is the project's single source of truth for integration decisions, progress, and provenance.

- `MASTER_PLAN.md` — engineering work sequence.
- `PROGRESS.md` — weighted progress and acceptance state.
- `ARCHITECTURE.md` — active application/runtime composition.
- `INTEGRATION_LEDGER.md` — donor/module decisions and canonical owners.
- `SOURCE_PROVENANCE.md` — exact upstream baseline and branch history.
- `DECISIONS.md` — decisions that prevent duplicate subsystems and unsafe merges.

Update this directory when code changes alter ownership, status, or test evidence. Do not count reading a PR, creating a test, or writing a document as a passed integration test.
