# Nullseed vs Claude (honest)

| Dimension | Claude-class LLM | Nullseed (this repo) |
|-----------|------------------|----------------------|
| Knowledge | Web-scale text | None (oracle tasks only) |
| Code gen | Strong natural language → code | Tiny 8-bit HVM synthesizer |
| Binary/bit mastery | Weak as *verified* low-level invent | **Target path** (BitPlane), currently weak too |
| Holdout invent | Not measured this way | Ladder: pure grow **1/4** |
| Consciousness / AGI | Not claimed | Not claimed |
| "God of code" | Marketing gap | **Not reached** |

## Where Claude is relatively weak (opportunity)
1. Guaranteed holdout on adversarial I/O (Nullseed gates exist; scores low).
2. Pure bit-level program invent without NL prior.
3. Immutable oracle discipline.

## Where Nullseed is far behind
1. General reasoning, APIs, large codebases, language design from scratch.
2. Neural weights / learning across tasks (Nullseed is search, not a trained net).
3. Human interface richness (Workbench/TUI only; no Live2D assets).

## Strategy (no hype)
Strengthen **verified bit/HVM invent** (BitPlane → pure grow) before claiming code-god or languages-from-scratch.
Neural "core" is **not** implemented; search synthesizer is the current kernel.
