# NOMEGA PASS20 — Capability Forge

## Goal

Build a large integrated development loop rather than another isolated micro-version.

## Implemented

1. `ExperienceWikiV1`: content-addressed raw experience records, persistent knowledge consolidation and skill-to-knowledge links.
2. `SkillCompositionEngineV1`: structured subset/count/order search over active executable skills using measured coalition evidence.
3. `AdaptiveEvidenceSchedulerV1`: conservative staged evidence scheduling with successive-halving style retention.
4. `AdversarialEvolutionArenaV1`: converts real execution failures into boundary/flip/zero/repetition test variants.
5. `CapabilityForgeV1`: orchestration layer joining execution-guided learning, wiki consolidation, skill composition, adversarial tests and staged verification.
6. Canonical registry: five new production targets.
7. Governance/version: 1.36.0-dev, PASS20.

## What is *not* claimed

The external research results are not treated as NOMEGA benchmark results. The new components provide a testable architecture; they require matched experiments before their effect is considered a capability gain.

## Verification contract

No failure is promoted into a positive label. No composition plan is treated as proof. No scheduler may bypass the final independent TinyVM/HVM checks.
