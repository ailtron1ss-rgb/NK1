# NΩ 1.3.0 Audit Notes

The project now distinguishes:
1. implementation completion;
2. integration maturity;
3. automated test coverage;
4. bounded evidence from holdout/adversarial evaluation;
5. demonstrated capability on current benchmarks.

Percentages in the release manifest are computed from the actual test/evaluation evidence captured during the release run. They are engineering/research maturity indicators, not intelligence scores.
