# NΩ 1.1+ Research Roadmap

1. Learn from actual runtime traces with route labels and verification outcomes.
2. Replace lexical task generation with latent/compositional and counterexample-driven curricula.
3. Train the NeuralInvent program expert on actual verified traces, not only synthetic arithmetic seeds.
4. Add proof/counterexample feedback to program generation.
5. Train the world model on multi-step traces and calibrate predictive uncertainty.
6. Build persistent skill lineage and measure transfer of each skill to unseen tasks.
7. Add real Android/Termux benchmarking with CPU/GPU/NPU, activation memory, battery and thermal telemetry.
8. Replace synthetic multimodal adapters with small learned perception encoders and cross-modal retrieval tests.
9. Add mixture-of-experts/conditional compute experiments behind isolated promotion gates.
10. Explore recurrent-state, state-space and verifier-guided architectures as falsifiable research tracks.
11. Require independent adversarial holdout improvement before any major checkpoint promotion.
12. Maintain rollback and protected-skill suites permanently.
