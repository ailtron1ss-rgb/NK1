# NΩ 1.4.0 — Next Research Priorities

1. Build a learned program-language interface so the shared latent state can generate executable programs for previously unseen task families.
2. Train on real execution traces with verified rewards, not only synthetic labels.
3. Couple world-model rollouts to program planning and verifier feedback.
4. Add compositional skill transfer across task families and test on held-out operators.
5. Add learned vision/audio encoders and grounded cross-modal tasks.
6. Measure continual learning across long task sequences with explicit forgetting curves.
7. Benchmark the same model on physical Android CPU/GPU/NPU/thermal/battery conditions.
8. Evaluate sparse-MoE and hybrid recurrent/attention research branches independently before promoting them.
