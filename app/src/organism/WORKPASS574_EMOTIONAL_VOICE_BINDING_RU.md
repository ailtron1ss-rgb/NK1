# WorkPass574 — синхронизация эмоции ответа с воплощением

**Дата:** 2026-10-27  
**Ветка:** `workpass70-source`  
**Категория:** личность / эмоции / голос / Live2D.

## Найденный разрыв

UI дорабатывал реплику Курису с полем `emotion`, прочитанным из предыдущего `get().snap`, а затем запрашивал свежий `uiSnapshot`. В `AvatarStage` сохранённая эмоция реплики имеет приоритет над текущей эмоцией организма при выборе высоты тона браузерного TTS. Следовательно, новая реплика могла получать прежнюю эмоцию, хотя Live2D уже отображал новое состояние.

## Изменение

- После ответа сначала читается новый канонический `uiSnapshot`.
- Эмоция и fallback-действие для реплики связываются с обновлённым состоянием организма.
- При временной ошибке запроса снимка реплика всё равно сохраняется в чате; ошибка обновления состояния не уничтожает текст ответа.

## Граница

Это исправляет порядок считывания эмоционального состояния, но не делает браузерный TTS эквивалентом серверного голосового контура. Согласованность тембра/просодии, акустического времени и Live2D должна быть отдельно проверена на реальном воспроизведении. Проверки и браузерный E2E в этом проходе не запускались.
